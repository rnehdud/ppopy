## 포함한 내용

- 보유 화장품 목록과 단일 관리 진입점
- 보유 제품 중에서 고르는 아침·저녁 루틴
- 루틴 확인과 한 번에 하나씩 답하는 점검 화면
- 포포의 질문·전송 중·답변 반영 안내, 소비자용 결과 문구
- 관련 UI 단위 테스트와 합성 화면 검토 입력

원본 컴포넌트·스타일을 재사용합니다. 합성 미리보기의 질문·결과·응답 지연은 화면 상태를 재현하는 테스트 입력이며 **실제 KB 판단·실제 사용자 기록·실제 서버 응답이 아닙니다**.

## 로컬 확인

Node 22+, npm을 사용합니다.

```bash
cd snapshots/app-ui-20261112/frontend
npm ci
npm run dev
```

표시된 로컬 주소에서 다음을 확인할 수 있습니다.

- `/`: 화장품·루틴·홈 등 작업 공간
- `/?screen=draft`: 아침·저녁 루틴 초안
- `/?screen=conversation`: 질문·선택·전송 대기. 아래 **합성 서버 응답 보내기**로 다음 상태를 확인합니다.
- `/?screen=result`: 소비자용 결과 표시

제품·루틴 변경은 현재 브라우저 실행 중 합성 메모리에만 반영됩니다. 새로고침하면 초기화됩니다. 브라우저 미리보기는 개발 서버/로컬 호스트에서만 표시합니다. `npm run build`는 컴파일 검사이며 공개 서비스 빌드를 활성화하지 않습니다.

```bash
npm test
npm run build
```
