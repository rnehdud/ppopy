# Ppopy iOS 앱 소스 — 팀 공유용 스냅샷

SkinAnalysis의 2026-11-09 작업 트리에서 React/TypeScript 화면, Capacitor iOS 프로젝트와 화면에 직접 필요한 설정을 선택해 가져왔습니다. 원본 커밋과 각 파일의 **복사 전** SHA-256은 [source-manifest.json](source-manifest.json)에 있습니다. 일부 화면은 원본에서 커밋 전이던 변경도 포함합니다. 이 공유본은 원본과 동일한 릴리스나 운영 앱 빌드가 아닙니다.

## 구성

- `frontend/src/`: 화면, 앱 흐름, 클라이언트 계약. `coursePreviewMain.tsx`가 이 저장소 전용 진입점입니다.
- `frontend/ios/`: Xcode 프로젝트, Swift 네이티브 브리지, Capacitor 설정과 앱 이미지.
- `skin_engine/config/`: 화면이 직접 import하는 설정 스냅샷. 백엔드나 실제 사용자 데이터는 포함하지 않습니다.

원본의 서비스 주소, 로그인 공급자 식별자, 서명 팀 설정은 공유본에서 제거하거나 예제값으로 대체했습니다. 원본의 수정된 Kakao SDK에 의존하는 인증·탈퇴 어댑터와 환경 바인딩은 공유본에서 비활성화했습니다. 이 스냅샷의 웹 진입점은 로컬 화면 검토용이며 API 프록시가 없고 네트워크 연결을 허용하지 않습니다. 실제 인증·제품 검색·저장·결제, 사용자 개인정보 수집과 운영 서버 연동을 사용하기 위한 앱이 아닙니다. 제품 예시는 합성 자료입니다. 원본에 있는 이력·제품 사진 실험 코드는 포함되더라도 기능 승인이나 공개를 의미하지 않습니다.

## 실행

Node.js 20 이상과 npm이 필요합니다. 저장소 루트에서:

```bash
cd app-snapshot/frontend
npm ci
npm run dev
```

출력된 `http://127.0.0.1:5173`을 브라우저에서 열고 **테스트 화면 보기**를 선택하세요. 입력은 합성 내용만 사용합니다. 프로덕션 전환 용도로 사용하지 마세요.

## iOS 프로젝트 살펴보기

macOS와 Xcode가 필요합니다. 위 `npm ci` 이후:

```bash
npm run ios:sync
open ios/App/App.xcodeproj
```

Xcode에서 `App` 스킴과 iOS 시뮬레이터를 선택합니다. 실제 기기 서명에는 각자의 설정이 필요합니다. 공유본에는 원본의 팀 서명과 로그인 연결이 없으며, 공유본은 Xcode 26.6 iOS 시뮬레이터 대상에서 서명 없이 빌드했습니다. 시뮬레이터 설치·실행은 별도 확인이 필요합니다. Capacitor가 생성한 웹 자산·빌드 결과와 로컬 설정은 커밋하지 않습니다.

## 변경 및 검증 범위

원본 실행 코드의 참고용 복사본과 별도로, 이 공유본은 진입점·Vite 설정·패키지 스크립트·CSP·iOS bundle/Info.plist·일부 설정을 공유용으로 변경했습니다. 원본 앱의 전체 테스트·서버·카탈로그·개인정보 기록·비밀값·배포 설정은 옮기지 않았습니다. 원본과의 의미 차이 또는 연동은 SkinAnalysis 쪽에서 검토해야 합니다. 스냅샷 테스트 결과는 실제 iOS 서비스·외부 계정·운영 DB 검증이 아닙니다.
