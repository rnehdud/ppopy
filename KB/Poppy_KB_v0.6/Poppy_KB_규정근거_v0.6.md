# Poppy KB v0.6 — 첨부 규정 근거·조건 검토

기준일: 2026-11-05. 이 문서는 사용자가 첨부한 **제2024-51호(2024-09-24)**를 정리한 역사적 근거층이다. 최신 법적 적합성/배합허용 판단 도구가 아니다.

## 1. 버전과 해석 경계

첨부 본문은 19쪽이며 원문 페이지별 추출 텍스트를 JSON `regulatory_source_pages` 및 별도 근거 JSON `source_pages`에 보존했다. 다음 카드의 문구는 조항 발췌·줄바꿈 정규화·표제와 관련 문구 결합이 포함될 수 있다. 정확한 원문은 해당 쪽을 확인한다. 조건식/서비스 연결은 편집 설계이며 법률 해석의 승인으로 간주하지 않는다.

공식 사이트에서 제2026-56호(2026-08-05)의 공고·개정 요지를 확인했지만, 전문 다운로드 접근에 실패하여 이번에는 첨부판과 전체 조문을 대조하지 못했다. 확정된 요지는 일부 샴푸 예외, 벤조페논-3 주의사항 신설, 인용조문 현행화다. 신설 항목의 정확한 문구·농도·개별 시행/경과조치와 현행 별표2 전체는 별도 확인이 필요하다.

2024년 일반 시행일, 제2조의 2025-07-10 시행 및 해당 포장 경과조치를 서로 구분한다. 날짜 하나만으로 모든 제품의 적용을 판정하지 않는다.

**의무 표시 조건 ≠ 개인의 안전 농도 ≠ 금지 성분 ≠ 서비스 병용 선호.** 규정에 열거되었다는 사실로 현재 배합이 허용된다고 추론하지 않는다.

### RG24-AHA-01 · AHA 광보호 표시

**원문 위치:** 별표1 2.나.9)가) · 첨부 17쪽 [F02]

**문구 발췌:** 햇빛에 대한 피부의 감수성을 증가시킬 수 있으므로 자외선 차단제를 함께 사용할 것(씻어내는 제품 및 두발용 제품은 제외한다)

**표시 적용조건의 편집 표현:**
```json
{
  "all": [
    {
      "field": "aha_percent",
      "op": "gt",
      "value": 0.5
    },
    {
      "field": "rinse_off",
      "op": "eq",
      "value": false
    },
    {
      "field": "hair_product",
      "op": "eq",
      "value": false
    }
  ]
}
```

**범위·주의:** AHA 0.5% 이하 제외는 9) 전체. rinse-off/두발 예외는 가)에만 적용.

**연결:** `B-I04`

**활성화 상태:** 역사적 참고. 현행 전문 대조 미완료, 자동 법적 적용 금지. 사용자 안내 유형: `snapshot_guidance_reference`.

## 4. 원문과 자동 사용안내를 분리하는 사례

첨부 제모제 조항의 붕산수 세척 문구는 `RG24-DEP-08`에 역사적 원문으로 보존했다. 이 문구를 사용자에게 자동으로 처치 지시하는 것은 차단한다. S41의 응급 안전 안내를 별도로 연결하고, 특정 세척액을 확보하느라 물 세척/전문 도움을 지연시키지 않도록 한다. 원문을 몰래 고치거나 국내 현재 법정 문구라고 새로 주장하지 않는다.

일반 얼굴/제한적 손 관리의 KB에 제모제·염모제·영유아 조항을 보관한 것은 해당 대상용 자가관리 모듈을 출시한다는 의미가 아니다. 원문 범위와 일반 사용 범위를 분리한다.

## 5. 검증용 미리보기와 실제 적용

`condition`은 제공된 제품 사실에 대한 3값(True/False/Unknown) 비교다. 날짜·경과·현행 전문 검토가 없으므로 기본 mode는 `current_version_review_required`를 반환한다. `historical_snapshot`을 명시한 경우에만 원문 조건의 일치/불일치/미확인을 미리볼 수 있다.
