# Poppy KB v0.6 — 변경사항

## 유지한 것

기존 v0.5의 40개 기준 카드 본문·근거·예외·검토 상태는 동일하다. 기존 203개 변수와 36개 배경 관계, 비공개 제형기술을 요구하지 않는 계약, 필터/제조업자 선택 기본값, 면도·월경·손 보습의 조건부 범위를 보존했다. 분류 참조/단계 태그는 갱신했다.

## 추가한 것

첨부 제2024-51호에서 25개 문구를 선택하여 표시조건·예외·원문 위치와 함께 기록하고 별표2 25개 이름/CAS를 보존했다. 19쪽 원문 추출 텍스트와 SHA-256를 연결했다. 2026-56호의 공식 공고·개정요지는 별도 레코드로 두고 전문 대조 미완료 표시를 유지했다.

## 이번에 하지 않은 것

실제 추천 엔진/문진 UI/제품 역할 자동매핑 구현, 임상효능 검증, 모든 성분 사전 완성, 실제 구매제품 정품 판정, 실시간 회수 감시, 2026 현행법 전문 일대일 대조, 앱·연구 데이터 수정.

원문의 강한 주장들을 추가로 승인하거나 이전 보류 주장을 일괄 편입하지 않았다. 구매 재고 참고 원칙은 서비스 정책이며 원문의 고온-수명 환산식을 사용하지 않는다.

## Codex 통합 우선순위

`rule_taxonomy` + `lifecycle_taxonomy`로 탐색 → 관련 카드 ID 수집/중복제거 → 제품 역할·실제 사용 부위/시점 확인 → `comparison_contract`에 따라 설명 → 근거·예외 보존. 규정 snapshot은 근거 조회와 검토 화면에서만 사용하고 현행 법정 판정 출력은 차단한다.

## 비교 방식

`v0_5_preservation_manifest`에 기존 파일 해시 및 기존 카드별 핵심 해시를 기록했다. 카드 해시는 분류/새 단계 태그만 제외하고 계산한다. 따라서 기존 근거 문구를 바꾼 것을 숨길 수 없도록 검증한다.
