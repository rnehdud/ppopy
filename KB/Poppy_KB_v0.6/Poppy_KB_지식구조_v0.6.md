# Poppy KB v0.6 — 구매·사용 단계, 활성성분 병용, 규정 근거 통합

기준일: **2026-11-05** | 버전: `0.6.0-draft` | 도메인 검토 전·운영 비활성

## 1. 이번 반영 범위

기존의 **기본 권장 상태 → 관찰 가능한 실제 사용/제품 정보와 비교 → 예외 확인 → 유지·안내·조정 → 후속 관찰** 흐름을 유지한다. 기존 v0.5의 40개 카드 본문·근거·예외는 보존했고, 구매·도입·병용·접촉 맥락 등 20개 카드를 추가했다. 분류·단계·참조 인덱스는 재생성했다.

총 60개 기준 카드 / 234개 변수 슬롯 / 9개 대분류 / 7개 사용 단계 / 25개 역사적 규정 선택 기록 / 25개 첨부판 알레르기 표시 항목. **변수 수는 설문 문항 수가 아니며, 규정 기록 수는 현행법을 전부 구현했다는 뜻이 아니다.**

이번 산출물은 KB 명세·문서·정적 검증용 참고함수다. 실제 앱·추천 엔진·AFA 연구 데이터·개인정보 저장소는 변경하지 않았다. 모든 규칙의 `active`와 `production_enabled`는 false다.

### 1.1. 출처와 정책의 구분

| 정보 | 저장 방식 | 제한 |
|---|---|---|
| 기존 v0.5 | 카드 원문과 근거·예외 보존 | 이번에 기존 모든 의학·성분 주장을 재검증한 것은 아님 |
| 사용자가 채택한 기본값 | U08·U09와 서비스 정책 D04 | 법정금지·개인 자극 확률·효능 상쇄로 설명하지 않음 |
| 첨부 2024년 고시 | F02, 원문 19쪽, 조건부 선택 기록 | 실제 현행법과 별도; 원문을 임의 교정하지 않음 |
| 외부 확인 자료 | S30–S41 및 기존 관련 출처 | 출처가 다루는 제품·대상·문구 범위를 보존 |

## 5. 활성성분 병용 비교 계약

**기본값:** 같은 부위에서 별도 레티노이드 제품과 AHA 또는 살리실릭애씨드 각질관리 제품, AHA와 살리실릭애씨드 각질관리 제품을 중첩하는 루틴은 기본적으로 권장하지 않는다. 필요한 한 종류를 우선하며 보습·광보호는 유지한다. [U09,D04]

레티놀/처방 레티노이드 사용 중 각질관리로 건조가 악화될 수 있다는 일반 안내는 S32, 특정 아다팔렌 제품의 AHA 회피 안내는 S33, 특정 트레티노인 제품의 살리실릭애씨드 병용 자극 주의는 S34에 근거한다. 이를 모든 화장품 조합의 절대 금기나 한국의 법정 병용금지로 승격하지 않는다.

| 상황 | 비교 원칙 |
|---|---|
| 별도 제품·같은 부위·같은 루틴 | B-G13~15 기본 비권장에 해당하는지 확인 |
| 아침/저녁 분리 | 시간대만 다르다고 자동 적합 판정하지 않음 |
| 서로 다른 날 | 빈도·현재 반응·제품 지시를 검토; 격일 자체가 안전 보증은 아님 |
| 얼굴과 발 등 서로 다른 부위 | 해당 중첩 경고와 분리하고 각 부위의 사용을 별도 확인 |
| 한 완제품의 복합 처방 | 별도 제품 중첩과 다른 경로로 제품 사용법 검토; 자동 금지/무자극 보증 아님 |
| 개별 의료진 사용 계획 | 처방을 임의 변경하지 않고 추가 화장품과 계획의 충돌 확인 |
| 시트릭애씨드만 검출됨 | 제품 역할·공개 목적 미확인이면 AHA 각질관리 제품으로 확정하지 않음 |
| 농도는 미공개이나 각질관리 목적이 명확 | 일반 병용 회피 안내는 가능; 농도·pH·흡수율을 생성하지 않음 |

이 정책에서 BHA는 살리실릭애씨드 각질관리 맥락이다. 성분 이름의 acid/salicylate 일부 문자열, UV 필터의 살리실레이트, 보존/항산화 성분의 BHA 약칭을 같은 역할로 매핑하지 않는다. PHA/LHA 및 미분류 레티노이드 유도체를 검토 없이 동등하게 확대하지 않는다.

## 6. 구매·수령·종료의 원칙

브랜드 공식몰과 확인 가능한 공식 판매처 등 신뢰할 수 있는 경로를 우선하되, 플랫폼과 실제 판매자를 구분한다. 올리브영 공식 경로는 사용자가 제시한 예시이며 이름 문자열만으로 정품 인증·화이트리스트를 생성하지 않는다. 제품의 구매 경로, 현재 품질, 개인 적합성은 별개다. [U08,S36,D04]

의심 제품은 피부에 발라 진위를 확인하지 않는다. 주문/판매자/포장 기록이 이미 있으면 보존하고 문의·반품 등을 검토한다. 영수증이 없다는 이유만으로 가품으로 판정하지 않는다. 회수는 제품·업체·제조번호·안내 범위를 일치시켜야 하며 조회에서 발견되지 않았다는 사실은 안전 인증이 아니다. 이번 산출물은 실제 사용자 제품의 회수 조회를 실행하지 않았다. [S36,S37,D04]

## 7. 규정 근거층의 운영

첨부 고시의 법정 분류는 `regulatory_product_taxonomy`에, 서비스 분류는 기존 C/M/P 등에 보존한다. 클렌징 오일·크림 등이 법정 기초화장용 제품에 속한다고 해서 서비스의 세정 분류에서 제거하지 않는다. [F02, 첨부 9쪽]

### 7.1. AHA 조건을 각각 보존

| 문구 | 첨부 2024년판 조건 | 주의 |
|---|---|---|
| 광보호 | AHA 0.5% 초과 + 씻어내는 제품 아님 + 두발용 아님 | 씻어내는/두발 예외는 이 문구에만 연결 |
| 일부 시험 사용 | AHA 0.5% 초과 | 앞 행의 예외를 자동 상속하지 않음 |
| 전문의 등 상담 | AHA 0.5% 초과 AND (AHA 10% 초과 OR pH 3.5 미만) | 초과/미만을 보존; 개인 안전 농도 아님 |

농도 미확인은 0이 아니다. 조건 충족 여부를 확인할 수 없으면 역사적 표시 적용 미확인으로 남기며, 일반 사용 안내를 모두 중지하지 않는다. 위 수치에서 ‘이하이면 안전’·‘병용 가능’이라는 결론을 만들지 않는다. [F02, 첨부 17쪽]

### 7.2. 알레르기 표시 목록

첨부 별표2의 25개 성분명/CAS를 원문대로 보존했다. 착향제 구성 성분의 해당 표시 조건은 씻어내는 제품 0.01% 초과, 씻어내지 않는 제품 0.001% 초과다. 개별 표시가 없다고 0으로 판단하지 않고, 목록 등재를 배합허용 또는 모든 사람에게 알레르기 발생으로 해석하지 않는다. 현행 별표2 전체 대조는 미완료다. [F02, 첨부 19쪽]

### 7.3. 특별 문구와 범위

분무형 선크림·제모 후 특정 제품·우레아 손/발 제품·살리실릭애씨드 제품의 연령 조건·특정 레틴아마이드 주의 등은 원문 제품 유형과 예외에 묶었다. 제모제의 10분은 허용 목표가 아니라 “10분 이상 방치 금지”이고, 세안제 임시 60초를 제모제/면도크림에 이식하지 않는다. [F02]

첨부의 붕산수 안구 세척 문구는 기록에 보존하되 자동 사용자 처치 안내에서 격리했다. 특정 세척액을 구하느라 흐르는 물 세척과 전문 도움을 늦추지 않아야 한다는 별도 외부 안전 근거를 S41로 연결했다. 원문과 외부 안전 해석을 같은 문장으로 바꿔 적지 않았다. 이 버전은 응급 진단·처치 엔진이 아니다.

**미확인:** 판단을 바꿀 때만 추가 질문/제품 근거 조회. 개인의 잘못으로 표현하지 않고 필요시 일반 원칙만 안내.

**권고:** 먼저 보유 제품의 실제 사용·시점·빈도를 확인한다. 건조하면 추가 보습을 검토하되 따가움·지속 증상은 별도로 확인한다.

**미확인:** 판단을 바꿀 때만 추가 질문/제품 근거 조회. 개인의 잘못으로 표현하지 않고 필요시 일반 원칙만 안내.

**적용:** 눈시림 이력이 있거나 눈 주변 도포 방법을 검토할 때. 모든 사용자에게 안구 설문을 요구하지 않는다. **대상:** 일반 성인 **부위:** 일상 얼굴 관리 및 관련 보유 제품

**확인 가능한 입력:** 선크림 사용 중 눈시림·눈물 등 자기보고 (`skin.eye_stinging`), 눈시림의 시작 시점·발한·물·닦임 등 발생 상황 (`skin.eye_symptom_context`), 눈 주변의 실제 도포 범위·방법 (`sun.periocular_application`), 발한 상황 (`sun.sweat`), 수영·물 접촉 (`sun.water_contact`), 수건·의복에 의한 닦임 (`sun.towel_contact`), 같은 활동 조건에서 편하게 사용한 선크림 이력 (`sun.prior_tolerated_products`), 그늘·모자·의복 등 보호 (`sun.shade_clothing`), 표시 사용법·주의사항 (`product.instructions`)

**차이:** 같은 제품·방식에서 반복 눈시림이 생겨도 그대로 눈 가까이에 사용하거나, 회피 후 눈 주변 보호가 사라짐.

**권고:** 해당 제품의 눈 가까운 부위 사용을 피하고 제품 표시를 따른다. 과거 잘 맞는 제품·도포 방식 또는 스틱 등 대안을 비교하며 선글라스·모자 보호를 병행한다. 선호 필터·제조업자라도 실제 반복 불편을 우선한다. 지속되거나 심한 통증·시야 변화는 일반 루틴 조정 대신 전문 진료로 연결한다.

**미확인:** 관찰 가능한 사실을 선택적으로 확인한다. 비공개 제형·원시험 보고서는 요구하지 않고 다른 기본 안내와 후보 비교를 계속한다.

**예외·유지 조건:** 제품의 눈 주변 사용 제한 / 개별 의료진 지시 / 일반 생활 안내 범위를 벗어나는 지속/심한 안구 증상

**출처가 뒷받침하는 범위:** AAD는 눈으로 흘러드는 것을 줄이기 위한 눈 주변 스틱 선택을 안내한다. FDA는 눈에 들어가지 않도록 적용하고 선글라스·모자 등을 병행하도록 안내한다. [U05][S17][S05][D02]

**서비스 해석:** 반복 불편의 우선순위와 특정 제품의 눈가 사용 회피는 사용자 요청을 반영한 서비스 정책. 모든 스틱의 무자극이나 필터 단독 원인을 보장하지 않는다.

**확인 가능한 입력:** 브랜드·정확한 제품명·시장 (`product.identity`), 제형 및 제품 유형 (`product.type`), 확인된 제형·성상과 상품명 구분 (`product.form_descriptor`), 해당 용기의 펌프·방울 단위 맥락 (`product.dispensing_unit_context`), 펌프·손가락 길이 등 사용량 대리지표 (`dose.proxy_amount`), 표시 사용법·주의사항 (`product.instructions`)

**부합:** 제품·용기 단위의 사용량과 용도를 구분함.

**차이:** 다른 용기 한 펌프를 같은 g으로 계산하거나 상품명만으로 사용 순서·기능을 결정함.

**권고:** 제품별 용도·표시를 확인하고 펌프/방울 기록은 해당 제품 내 상대 변화로 사용한다. 확인된 토출량·밀도 없이는 정량 환산하지 않는다.

**미확인:** 일반 안내는 가능하되 개인화된 차이는 만들지 않는다. 필요한 관찰 정보만 선택 질문.

**예외·유지 조건:** 개별 의료진 지시와 충돌하면 해당 권고를 별도 검토

**출처가 뒷받침하는 범위:** F01은 명칭과 성상, 용기에 따른 방울/펌프 차이를 설명. 수치 범위는 원문 제안값으로 보존하고 보편 환산값으로 채택하지 않음. [F01][D03]

**서비스 해석:** 관찰 정보의 표준화 규칙으로, 특정 제형의 효능 우월성을 선언하지 않음.

**하지 않는 판단:** 모든 한 펌프=0.2g / 투명 제형=보습 성분 없음 / 앰플=수용액 / 피부에서 사라지는 속도=흡수량

**상태:** 검토용 초안. `active=false`, `production_enabled=false`.

**부합:** 해당 기본 상태에 부합하는 사실이 확인되고 예외·상위 제약과 충돌하지 않음.

**차이:** 표시목록에 있다는 이유만으로 전 사용자 금지하거나 미표시를 성분 부재로 처리함.

**미확인:** 관련 정보만 선택 확인하고 필요시 일반 기준을 안내한다. 미확인을 정상·0·위반으로 대체하지 않는다.

**예외·유지 조건:** 알레르겐 정체가 불명확 / 첨부판 이후 변경 여부가 아직 완전히 대조되지 않음

**출처가 뒷받침하는 범위:** 첨부 별표2의 25개 항목과 wash-off/leave-on별 표시 역치를 원문대로 보존한다. [F02][D04]

**하지 않는 판단:** 미표시=0% / 향료 목록=전원 블랙리스트 / 표시 기준 미만이면 개인 알레르기 불가능 / 벤질살리실레이트를 BHA 각질제로 처리

#### B-G02 · 제품별 용량·빈도, 성분 농도와 구분

**적용:** 양·횟수·농도를 변경하려 하거나 고함량/많이 바름을 동일시하는 경우. **대상:** 일반 성인 **부위:** 일상 얼굴 관리 및 관련 보유 제품

**권고:** 먼저 어느 제품의 어떤 사용 변수를 바꾸는지 구분한다. 효과·흡수량을 추정하지 않고 해당 축의 기준으로 연결한다.

**미확인:** 판단을 바꿀 때만 추가 질문/제품 근거 조회. 개인의 잘못으로 표현하지 않고 필요시 일반 원칙만 안내.

**예외·유지 조건:** 개별 치료·제품 지시 / 농도가 미공개인 경우 수치 비교 보류

**출처가 뒷받침하는 범위:** v0.1에 보존된 위해평가 자료는 양·농도·노출조건을 구분한다. 소비자 공통 최적량을 제시하는 자료는 아니다. [D01][S01]

**서비스 해석:** 측정 흡수율 없이 효과·위험 수치를 만들지 않기 위한 서비스 기준이다.

**하지 않는 판단:** % 단위이면 모두 고함량 / 전성분 순서로 농도 산출 / 임의의 전제품 감량

**권고:** 관련 사용법을 조회하고 적용 범위를 고친다. 충돌이 해소되지 않으면 해당 권고만 보류한다.

**미확인:** 판단을 바꿀 때만 추가 질문/제품 근거 조회. 개인의 잘못으로 표현하지 않고 필요시 일반 원칙만 안내.

**예외·유지 조건:** 자료 충돌·버전 불명확 / 개별 의료진 계획

**서비스 해석:** 표시 사용법을 모든 단순 안내의 필수 baseline으로 만들지 않는다. 안전 우려·개별 진료계획을 제조사 문구가 무조건 덮어쓰지도 않는다.

**하지 않는 판단:** 모든 제품의 사용법 확보 전 기본 안내 불가 / 일반 기준으로 처방 변경

**권고:** 충돌하는 해당 권고를 보류하고 기존 지시·전문 상담을 확인한다. 진단·처방 변경·응급 중증도 분류는 하지 않는다.

**미확인:** 판단을 바꿀 때만 추가 질문/제품 근거 조회. 개인의 잘못으로 표현하지 않고 필요시 일반 원칙만 안내.

#### B-H01 · 월경 관련 반복 피부 변화는 실제 상태와 함께 해석

**적용:** 월경 관련 피부 변화를 본인이 보고하거나 자발적으로 기록에 동의한 경우. **대상:** 해당 행위·맥락이 있는 성인 **부위:** 사용자가 기록하기 원하는 부위

**부합:** 본인의 반복 패턴과 실제 현재 변화를 함께 기록함. 기록하지 않는 선택도 허용.

**차이:** 주기 단계만으로 제품 실패/원인을 단정하거나 모든 사람에게 동일한 증량·감량을 적용함.

**권고:** 원하는 범위에서 반복 변화를 간단히 기록하고 현재 건조감·트러블·따가움에 맞는 기존 규칙을 검토한다. 모름/거부면 일반 사용 안내를 계속하며, 평소와 다르게 심한 반응은 주기로 정상화하지 않는다.

**미확인:** 일반 안내는 가능하되 개인화된 차이는 만들지 않는다. 필요한 관찰 정보만 선택 질문.

**예외·유지 조건:** 동의 거부/해당 없음이면 질문 생략 / 주기가 불규칙하거나 약물 변화가 있으면 단계 추정 금지 / 평소와 다른 심한/지속 변화는 별도 검토

**하지 않는 판단:** 성별만으로 생리일 필수 수집 / 배란일·호르몬 농도 추정 / 월경기=반드시 건조 / 황체기=스킨 자동 증량 / 월경 중이니 따가워도 정상 / 피임약/호르몬약 임의 변경
