# 건조함을 선택한 사용자의 루틴을 어떻게 점검할까

**뽀피 KB 검토안 · 2026-11-21 · 성인의 일상적인 얼굴 관리 · 검토 대기**

**바꾸려는 결정은 “건조하다 → 보습제를 언제 바르는지 묻기”의 첫 단계다.** 예를 들어 “세안하면 당기고 크림을 바르면 편해져요”라고 한 사람에게는 세안할 때 무엇을 하는지 묻는 편이 더 유용하다. 같은 사람이 난방을 켠 사무실에서 오후에 다시 당긴다면, 그때의 불편도 별도로 살펴볼 수 있다. 한 번의 점검은 사용자가 해볼 만한 변화 하나와 그 근거를 제시하면 충분하다. 바꿀 행동을 찾지 못했을 때도 그 사실을 결과로 남긴다.

## 1. 현재 뽀피에서 재현한 빈틈

로컬 회원 AFA `member-whole-afa-v7`에 같은 합성 저녁 루틴을 두 번 넣었다. 클렌저 `CLN-0001`과 보습제 `official-lead-celimax-52`를 실제 사용으로 등록하고 기본 점검, 현재 불편감 ‘없음’으로 시작했다. 두 실행의 시작 입력은 선택한 고민만 다르다. 해당 질문이 나오면 ‘약간 촉촉할 때 보습’, ‘세게 문지름’, ‘별도 예외 없음’으로 답하도록 했다.

| 선택한 고민 | 실제로 물은 내용 | 실제로 끝난 결과 |
|---|---|---|
| 건조함 | 보습 시점 → 이 보습제를 쓸 때 별도 불편·지시가 있는지 | `keep_prompt_moisturizing`. 세안 방법을 묻기 전에 2문항으로 종료 |
| 세안 방법 | 문지르는 힘 → 이 세안에 별도 불편·지시가 있는지 | `reduce_rubbing`. 같은 루틴에서 힘을 줄이는 안내에 도달 |

건조함 경로에서 강한 세안을 부정한 사람은 없었다. **그 행동을 밝혀낼 질문이 나오지 않았다.** 현재 기본 관심 주제는 건조함에 보습 시점과 보습감 두 개를 연결한다. 이미 들어온 행동 증거, 다른 안전 신호, 상세 점검 요청이 있으면 다른 카드도 열릴 수 있다. 위 결과는 로컬 로직 재현이며 실제 이용자 빈도나 AWS 배포 버전을 측정한 값은 아니다. |---|---|---|

| B-I03 변화와 시점, B-G05/G07 추가 관리, B-B01 지속 불편·개별 지시 | 환경·변경 이력·기존 지시를 검토할 KB는 있다. R02는 세정 조성과 노출, R21은 환경, R30은 수분·유분·장벽 측정의 구분을 명시한다. | 시점과 단서에 따라 후보를 열고, 배경 관계만으로 행동을 확정하지 않음 |

## 3. 질문과 안내 문구

루틴에 기록된 **실제 사용 제품·얼굴 부위·아침/저녁 회차**와 이번에 사용자가 직접 말한 정보를 먼저 쓴다. 예정표나 제품 보유만으로 그날 사용을 확정하지 않는다. 아래 행들은 질문 후보다. 한 사람에게 표 전체를 묻지 않는다.

**시점 단서가 전혀 없을 때의 첫 질문**  
“최근 얼굴이 당겼던 때를 떠올려 볼까요? 언제 가장 신경 쓰였어요?”  
선택지 · 씻기 전부터 / 씻고 나서 아무것도 바르기 전 / 제품을 바른 직후 / 아침엔 괜찮다가 낮에 / 그때그때 달라요 / 잘 모르겠어요. 하나를 골라도 다른 시간대에 불편이 없었다고 기록하지 않는다. “씻고 나면 당겨요”라고 이미 말한 사람에게는 이 질문을 건너뛴다.

| 사용자가 준 단서 | 다음 질문 예시 | 어떤 답에서 어떤 안내가 달라지나 |
|---|---|---|
| **세안 직후, 보습 전** · 평소 방법을 모름 | “그때 얼굴을 헹군 물은 뜨겁게 느껴졌나요, 미지근했나요?” 이미 물 온도를 알면 접촉·마찰 질문으로 이동한다. | 뜨거웠음 → “다음 세안에는 물을 미지근하게 맞춰 보세요.” 미온수 → 온도 변경을 제안하지 않고 남은 단서만 본다. 찬물·모름 → 과도한 세안 판정 보류. **B-C01** |
| **거품을 오래 마사지하거나 일부러 둠** | “그 세안제는 손끝으로 펴 바르고 헹구나요, 계속 문지르나요, 아니면 거품을 잠시 올려두나요?” | 일반 씻어내는 제품·별도 지시 없음 + 오래 문지름/의도적 대기 → “손끝으로 부드럽게 펴 바른 뒤 충분히 헹궈 보세요.” 몇 분이라는 답만 있으면 행동을 한 번 확인한다. 팩·필링·의약품·대기 지시 제품은 이 분기 제외. **B-C03/G03/C06** |
| **세안 도구나 수건을 언급** | 수건 얘기가 나왔으면 “물기를 닦을 때 수건으로 가볍게 누르나요, 비벼 닦나요?” 세안 중 힘이 단서라면 그 행동만 묻는다. | 강하게 비벼 닦음 → “수건으로 가볍게 눌러 물기를 닦아 보세요.” 세게 문지름 → 해당 세안의 힘만 줄인다. 수건 사용 자체·‘뽀득한 느낌’만으로 마찰이나 장벽 손상을 확정하지 않는다. **B-C02** |
| **한 회차에 두 번 씻음 / 하루 중 추가 세안** | “마지막에 한 번 더 씻는 건 무엇을 지우기 위해서예요?” 선택지 · 화장이나 선크림 / 땀·오염 / 특별한 이유 없이 습관적으로 / 다른 이유 / 모름. | 필요한 제거를 마친 뒤 습관적으로 같은 세정을 되풀이함이 확인됨 → “이미 씻은 뒤 습관으로 한 번 더 하는 단계만 빼보세요.” 내수성 선크림·메이크업이면 실제 제품의 제거 지시와 그날 사용한 세정제를 먼저 본다. 운동 뒤 추가 세안이나 ‘2단계’만으로 줄이지 않는다. **B-C05/I01** |
| **특정 클렌저를 쓴 날이나 바꾼 뒤 반복** | “그 제품을 쓰기 전에도 같은 때 당겼나요?” 앞선 사용을 기억하지 못하면 그 값을 보존한다. | 확인된 변경과 당긴 회차만 기록. 정확한 제품·버전·표시를 확인한다. 확인된 알칼리성도 단독 교체 조건이 아니다. pH를 모르면 사용자에게 수치를 묻지 않고, 독립적으로 조정 가능한 사용법을 안내한다. **B-C04/I03/G12** |

씻기 전부터 당기거나 때가 일정하지 않으면 세안 한 회차에 원인을 붙이지 않는다. “요즘 달라진 제품이나 생활 장소가 있었나요?”의 답이 실제 안내를 바꿀 때만 묻고, 단서가 없으면 종료한다. 수면·식사·물 섭취·호르몬은 이러한 일반 건조 호소만으로 전수 수집하거나 해결책으로 제시할 근거가 없다.

## 4. AFA의 선택·종료 기준

1. **안전 조건을 먼저 적용한다.** 이미 확인된 통증·지속 따가움·개별 지시가 있으면 관련 행동을 보류한다. 현재 세정 전용 질문은 ‘지금 불편감’ 전체를 묶어 묻는다. 건조감만 보고한 사람에게 세정 분기를 열려면 ‘평소 당김만 있음’과 ‘그 외 지속 불편·특수 지시’를 구별하는 검토된 세정용 질문이 필요하다. 기존 `exception`을 프로그램에서 묵시적으로 `ordinary`로 바꾸면 안 된다.
2. **확인된 단서에 맞는 행동 후보를 먼저 연다.** 예를 들어 세안 직후라면 같은 회차의 B-C01/C02/C03/C05가 후보가 된다. 사용자가 ‘두 번 씻는다’고 했다면 가장 먼저 반복의 목적을 묻는다. 구체적 단서가 없다면 물 온도처럼 짧게 답해 행동을 결정할 수 있는 항목을 먼저 시도한다. 이 순서는 질문 비용에 대한 서비스 설계이며 개인별 원인 가능성 순위가 아니다.
3. **다른 답이 실제 안내를 바꿀 때만 한 문항을 낸다.** 이미 기록된 ‘뜨거운 물 + 예외 없음’으로 온도 안내가 충분하다면 온도나 pH를 다시 묻지 않는다. 두 행동이 모두 확인되면 사용자가 하기 쉬운 변화 하나부터 제안할 수 있다. 다음 회차에는 실제로 무엇을 바꿨는지와 같은 시점의 체감만 확인한다.
4. **한 항목의 ‘유지’를 고민 전체의 해결로 처리하지 않는다.** 보습 뒤 완화돼도 세안 직후 당긴다는 관찰은 살아 있다. 보습 제품 미등록·보류도 독립적인 세안 분기를 닫지 않는다. 반대로 보습 후 편안하고 세안 습관에도 조정 근거가 없으면 제품 교체를 만들지 않는다.
5. **기존 전체 예산 4문항 안에서 종료한다.** 시점·실제 사용·안전 확인도 새로 물으면 예산에 포함한다. 예산 안에 행동과 예외를 모두 확인할 수 없는 질문은 후순위로 둔다. 모름·거절·상충·중단이면 확인한 관찰과 미확인 항목만 표시한다. 예시 문구는 “세안 뒤 당긴다는 점까지 확인했어요. 이번 답만으로 바꿀 세안 습관을 정하기 어려워요.”다. [전체 질문 예산](../../skin_engine/config/dev_whole_routine_afa.json)

### 사용자가 준 사례에 적용하면

> 사용자 · “씻고 나면 바로 당겨. 수건으로 닦고 거의 바로 크림을 바르는데 바르면 괜찮아.”
>
> 뽀피 · “크림을 바르면 편해지고, 그전에 세안을 마쳤을 때 당기는군요. 그때 얼굴을 헹구는 물은 뜨겁게 느껴지는 편인가요?”
>
> 사용자 · “응, 저녁 샤워할 때 뜨거운 물로 같이 씻어.”
>
> 결과 · “저녁에는 얼굴을 헹굴 때만 물을 미지근하게 맞춰 보세요. 크림은 지금보다 서둘러 바를 필요는 없어 보여요. 다음에 씻고 나서도 비슷하게 당기는지 알려주세요.”

이 예시는 얼굴·저녁 클렌저 실제 사용과 일반 안내 가능 여부가 확인된 경우다. 첫 답에서 저장할 내용은 세안 직후 당김, 수건 사용, 곧바로 도포, 보습 후 편안함이다. 수건으로 비볐는지, 발랐을 때 피부가 촉촉했는지, 장벽이 손상됐는지는 미확인이다. 같은 첫 답에 “미온수로 씻는데 거품을 올리고 양치한 뒤 헹궈”라고 이어지면 물 온도 조정은 사라진다. 이때는 일반 세안제인지와 별도 대기 지시를 확인한 뒤 B-C03으로 전환한다.
