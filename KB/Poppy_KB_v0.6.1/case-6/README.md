# 선크림을 바른 날의 저녁 세안

2026-11-19 · 실제 카탈로그와 합성 개발 계정 · KB B-I01, 회원 AFA v7·로컬 개발 앱

## 사례 6. 같은 루틴에서 세정제만 바꾼 결과

아침에는 **닥터지 그린 마일드 업 선 플러스 50ml**, 저녁에는 **로벡틴 아쿠아 딥 클렌징 워터 400ml와 에스트라 아토베리어365 크림 80ml**를 등록했다. 피부 상태는 ‘현재 불편감 없음’, 고민은 ‘최근 트러블’로 두었다. 저녁 목록에 폼이나 밀크를 추가하지 않고 실제 사용 답만 바꿨다.

| 차례 | 질문 | 공통 답 |
|---|---|---|
| 1 | 따로 받은 진료 지시가 있거나, 통증이 심하거나 불편이 계속 심해지나요? | 둘 다 없어요 |
| 2 | 오늘 쓰는 제품이나 루틴에서 더 살펴볼 점이 있나요? | 잘 모르겠어요 |
| 3 | 최근 옷이나 마스크, 보호장비가 그 부위에 반복해서 쓸렸나요? | 그래요 |
| 4 | 이 선크림을 바른 날 저녁에 실제로 어떻게 지웠나요? | 아래 네 답을 각각 선택 |

네 결과에 부드럽게 세안하는 방법과 반복해서 쓸리는 부위를 돌보는 안내가 공통으로 표시됐다. 네 번째 답에 따른 세정 안내는 다음과 같다.

| 실제로 쓴 세정제 | 개발 앱의 안내 |
|---|---|
| [일반 클렌징 워터만](water.png) | 일반 클렌징 워터로만 닦으면 이 선크림이 충분히 지워지지 않을 수 있어요. 다음에는 저녁에 클렌징폼으로 한 번 씻거나, 선크림 제거용으로 표시된 클렌징 밀크를 사용해 보세요. |
| [클렌징폼](foam.png) | 이 선크림은 폼 클렌저로 한 번 씻는 조건에서 씻김성을 시험했어요. 지금처럼 저녁에 폼으로 부드럽게 씻어 주세요. |
| [선크림 제거용 표시가 있는 밀크](milk_label.png) | 선크림 제거용으로 표시된 밀크를 쓰고 있어요. 선크림에 별도 지시가 없다면 밀크에 적힌 양과 닦거나 헹구는 방법을 따라 주세요. |
| [제거 용도를 모르는 밀크](milk.png) | 밀크의 용기에서 선크림 제거 용도와 닦거나 헹구는 방법을 확인해 주세요. 표시를 확인하기 어렵다면 이 선크림은 저녁에 클렌징폼으로 한 번 씻는 방법을 선택할 수 있어요. |

430px 너비의 Chromium에서 개발 앱에 로그인해 네 번째 답을 워터 → 폼 → 제거용 밀크 → 용도 미확인 밀크 순으로 수정했다. 같은 결과 영역에서 앞선 워터 안내가 사라지는 것을 확인하고 마지막 점검을 저장했다.

## 다른 선크림에서 달라진 질문

합성 개발 계정 A에 **싸이닉 엔조이 워터프루프 수분 선크림 80ml**와 저녁 **센카 클렌저**를 등록하고 세안 방법을 고민으로 골랐다. 제품명에서 워터프루프 표시는 확인할 수 있고, KB에 제품별 제거 방법은 등록되어 있지 않다. 첫 질문은 “이 선크림에는 어떻게 지우라고 적혀 있나요?”였다.

| 사용자가 읽은 선크림 표시 | 실제 세정 | 앱의 판단 |
|---|---|---|
| 보지 않았거나 잘 모름 | 폼 | 사용한 폼에 워터프루프 제거 용도가 있는지 확인 |
| 같은 답 | 워터프루프 제거용 표시가 있는 세정제 | 선크림에 별도 지시가 없으면 해당 세정제 사용법 유지 |
| 클렌징 오일을 쓰라고 적혀 있다고 응답 | 폼 | 다음 세안에 표시대로 클렌징 오일 사용 |
| 같은 답 | 오일 | 지금처럼 표시 방법대로 사용 |

오일 지시는 문답 경로를 검증하기 위해 입력한 가상 사용자 답이다. 싸이닉의 확인된 제품 표시로 카탈로그에 기록하지 않았다. [개발 앱 API의 실제 답변과 안내](other-sunscreen.json)

## 근거와 재현

- 닥터지의 해당 등록 버전에는 제품 자료의 폼 클렌저 1회 시험 조건을 연결했다. 로벡틴 워터와의 조합, 밀크와의 조합에는 직접 측정한 제거율이 없다. 워터 단독에 대한 문구는 제거가 부족할 수 있다는 안내이고, 밀크 선택은 사용한 제품의 제거 용도를 전제로 한다. [닥터지 제품 자료](https://m.gsshop.com/prd/prd.gs?prdid=1103743433) · [선크림 제거 용도를 표시한 밀크 예](https://www.nomadiaskin.com/products/blue-calming-panthenol-1-cleansing-milk)
- 내수성과 세정 방법을 비교한 연구의 물 세안은 맹물이다. 결과를 클렌징 워터의 제거율로 옮기지 않았다. 워터프루프라는 이름만으로 이중 세안을 권하지 않는다. [Chen 등의 원 연구](https://pubmed.ncbi.nlm.nih.gov/31157512/)
- 개별 시험 조건은 제품 ID와 버전이 모두 일치해야 적용한다. 그 외에는 실제 제품명에 있는 워터프루프·이지워시 표시, 사용자가 읽은 제거 지시, 실제 세정 방법을 구분한다. 여러 선크림 중 어느 것을 썼는지 확인할 수 없으면 특정 제품에 방법을 귀속하지 않는다. [KB 실행 규칙](../sunscreen_removal_review.json)
- 세안 고민에서 ‘밀크’를 고르고 질문이 남으면 제거 용도 표시를 한 번 더 묻는다. 사례 6처럼 마지막 문항이면 밀크의 표시 여부를 같은 문항에서 고른다. 제품을 쓰지 않았거나 방법을 모르면 세정제 변경을 제안하지 않는다.

개발 앱에서 네 번째 답을 수정한 뒤 저장한 점검을 다시 열어, 마지막으로 선택한 밀크 안내와 네 개의 답이 보존된 것을 확인했다. 위 화면과 결과는 2026-11-19 개발 앱의 합성 사례 기록이다.
