# 뽀피 KB v0.6.2 · 세안 후 당김

2026-11-22에 고정한 개발·비교용 명세다. 기존 60개 카드 중 7개의 관찰·질문·예외 또는 제품 근거 연결을 갱신했다. 새 회원 앱에 이식할 때의 정답 기준과 실제 배포본을 구분한다. [전체 명세](Poppy_KB_seed_v0.6.2.json) · [파일별 SHA-256과 부모 버전](MANIFEST.json)

| 이미 확인한 사실 | 점검에서 달라지는 내용 |
|---|---|
| 세안 직후 당기고 보습하면 편해짐 | 두 경험을 따로 기록한다. 이 회차에서 바꿀 수 있는 세안법을 확인한다. |
| 약산성·약알칼리성 제품 | 같은 제품 ID·버전에 대한 국내 브랜드 표시나 조건이 기록된 완제품 시험을 읽는다. pH만으로 기존 제품 교체를 제안하지 않는다. 미확인·충돌이면 pH 설명만 보류한다. |
| 세안 전체 3분 | 제품을 바르고 헹구기 전 실제로 무엇을 했는지에 따라 행동이 달라질 때 한 번 확인한다. 시간만으로 과세안을 판정하지 않는다. |
| 강하게 문지름 / 수건으로 비벼 닦음 | 첫 경우는 세안 중 손의 힘을 줄이고, 두 번째는 닦을 때 가볍게 누르는 안내가 가능하다. 단순히 수건을 썼다는 답에서는 두 행동 모두 미확인이다. |
| 별도 지시 없는 일반 세안제를 오래 문지르거나 거품을 일부러 둠 | 부드럽게 펴 바르고 충분히 헹구도록 안내한다. 제품에 대기 지시가 있으면 그 사용법을 우선한다. |
| 부드럽게 썼는데 같은 세안제 사용 뒤 당김이 반복되고 비교를 원함 | 기존에 편안했던 세안제와 제거 목적·표시를 비교한다. 재사용 실험·원인 단정·자동 구매는 권하지 않는다. |
| 현재 지속되는 통증·따가움이나 개별 지시 | 일반 변경을 보류한다. 관찰한 시간이나 pH가 이 결정을 뒤집지 않는다. |

국내 단품 두 건은 브랜드 사용법, 전성분 전체 순서, 현재 카탈로그 ID·버전을 대조해 포함했다. 에뛰드의 ‘약산성 5.5’는 제품 표기이며, 레이어랩은 ‘약알칼리성’으로 표시하고 수치를 제시하지 않는다. 두 값 모두 제조사가 표시한 내용으로 기록했다. 세안 방법은 미국피부과학회 안내에 근거한다. 완제품 pH의 의미는 계면활성제 조성을 함께 바꿔 본 전완 연구의 적용 범위에서 해석했다. 여러 세정제의 사용 후 당김이 서로 다를 수 있다는 연구는 특정 사용자의 원인이나 장벽 손상을 판정할 근거로 사용하지 않았다. [AAD 세안 안내](https://www.aad.org/public/everyday-care/skin-care-basics/care/face-washing-101) · [Hawkins 등](https://doi.org/10.1111/ics.12721) · [Bennett-Kennett 등](https://pubmed.ncbi.nlm.nih.gov/37771342/)
