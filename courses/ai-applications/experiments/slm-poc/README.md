## 実行用ファイル

各フォルダの `実行ファイルと不足.txt` に、代表的な実行方法、コピーしたファイルと別途必要な環境を記載しています。`runtime-inventory.json` はコピー元・サイズ・ハッシュの一覧です。

- 7フォルダ合計653ファイルをコピーしました。指定したコピー対象の未発見はありません。ただし、動的に参照するファイルや過去の全実験条件まで揃ったことを意味しません。
- モデル重みや実行エンジンなどの大きなファイルはPC内にコピーしていますが、各フォルダの `.gitignore` でGitへの追加対象から外しています。GitHubから取得しただけでは揃いません。一部のデータも権利確認が必要なため除外しています。
- Python環境と必要なライブラリは各自で用意してください。実GPUでの学習・推論は今回実行していません。実行方法の詳細やその他の制約は各フォルダの一覧を確認してください。
