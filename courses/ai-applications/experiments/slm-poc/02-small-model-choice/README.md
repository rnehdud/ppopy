# 小さいモデルで「何をするか」を選ぶ

## 概要

症状の限定試験4/20→19/20。ツール選択13/24→19/24。旧kotraj候補選択37/120→87/120の一方、既出の肌の動作は20/23→15/23。

## 元の実験記録

### E07 症状4択を2モデルで追加学習

- 内容：ko-decisionとEXAONE-JEVに120判断ずつ。症状ごとの4択を学習。
- 結果：新しい8会話10ターン：ko-decision状態0/10→8/10、会話0/8→6/8。JEV状態0/10→6/10、会話0/8→4/8。両モデルval120/120。
- 条件・限界：同一作者の小規模合成例。ツール選択・製品・自由な値生成は対象外。

### E08 6000判断の症状学習

- 内容：合成症状5000＋WoS由来の暫定非更新1000判断。
- 結果：別の20会話：前4/20、開発で選んだ2000判断時15/20、最終6000判断時19/20。状態ターン18/45→44/45。
- 条件・限界：合成20会話で95%。開発規則の選択モデルは75%。製品やツール呼び出しの完全一致ではない。

### E09 3235判断で記録・検索・表示などを選ぶ

- 内容：症状モデルへツール選択1290等を追加。1発話1ツール。
- 結果：ツール選択13/24→19/24。会話2/8→6/8。ツールと状態のターン7/18→14/18（選択重み）、最終15/18。
- 条件・限界：候補から選択し模擬関数を実行。自由な引数生成・連続実行ではない。

### E10 質問を変えたとき答えも変わるか

- 内容：はい・いいえ・不明と旧動作保持を2400判断追加。
- 結果：新しい質問16問は前後とも16/16。既出ツール19/24→選択19/24・最終22/24。既出会話6/8→選択4/8・最終6/8。
- 条件・限界：質問の試験は学習前に満点。既出の会話は新しい最終テストではない。

### E11 公開例4400判断：名前は合っても値で失敗

- 内容：ツール候補と引数候補から選ぶ学習。
- 結果：公開由来dev70/100→84/100。一方、別の未知ツール27要求の全条件22/27→20/27。学習後の未指定値での正しい停止0/6。
- 条件・限界：引数は提示候補から選ぶ。自由なJSON生成ではない。模擬実行のみ。

### E12 FunctionChat 600判断

- 内容：公開データ追加学習前後の選択を比較。
- 結果：332/600→365/600。呼ぶ86/100→91/100、拒否10/100→25/100。未知名を含む呼び出し233/372→247/372。
- 条件・限界：候補選択の試験。名前と値の自由生成や外部実行ではない。

### E13 kotrajの少量確認と200例

- 内容：14種類の小規模試験後、200例＋旧40判断へ拡大。
- 結果：最初の8問は5/8→5/8。200例条件の60問は25/60→32/60。ただし呼び出し7/30→6/30、呼ばない18/30→26/30。
- 条件・限界：同じ固定ツール群の合成出典。選択だけで値は未実行。8問と60問は別の評価。

### E14 Kaggleで旧選択モデルを拡大学習

- 内容：kotraj由来の候補選択学習を拡大。
- 結果：新120問37/120→87/120。呼ぶ7/76→58/76、呼ばない30/44→29/44。旧60問25/60→49/60。既出肌23問の動作20→15、状態20→15。
- 条件・限界：ツール候補を選ぶ試験。自由な値生成ではない。保存結果は87、会話に貼られた88ではない。
