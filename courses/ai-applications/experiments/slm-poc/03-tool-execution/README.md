# 選択をツールにつなぐ・連続実行する

## 概要

単純な繰り返しだけでは正しい操作順は増えなかった。限定した症状条件では30/30または28/30の成功があったが、自然な依頼や未知関数へ広げると失敗が増えた。

## 元の実験記録

### E15 旧kotrajの選択を実ツールへつなぐ

- 内容：一時的なローカル関数を呼ぶ。さらに次の選択へ結果を戻す。
- 結果：22ターンの正しい選択12→11、状態20→20、実行エラー0→0。10会話の正しい操作順2→1、繰り返し遮断7→8。
- 条件・限界：引数なしの一時ローカルツール。Qwen・外部サービスは不使用。期待順に別解の余地がある少数合成例。

### E28 実行結果を返すだけで次へ進めるか

- 内容：ツール結果を履歴へ戻す3条件。追加学習なし。
- 結果：正しい操作順と終了は3条件とも0/20。
- 条件・限界：狭い合成の連続操作試験。

### E29 選択役・停止役と対比較の追加

- 内容：選択だけ、停止だけ、両方、閾値変更、正誤対比較を分離。
- 結果：v27全24例1→選択4・停止7・両方11。v28全40例10→13だが必要操作完了7/20→4/20。v29全32例12→通常学習19・対比較17。
- 条件・限界：評価集合は実験ごとに違う。v29は同じ32例で通常学習と対比較を比較。

### E30 候補数・説明・実行条件を変更

- 内容：候補を増やす、説明を残す、呼ぶ条件と終了条件を分ける。
- 結果：v31旧32例19→24、新24例0→0。v32新24例10→14。v34狭い40例30→36（90%ちょうど）、不要継続6/20→0、必要操作完了19/20のまま。
- 条件・限界：旧例と新例を区別。v34は現在のkotrajでも90%超でもない。

### E31 入力と正解を合わせ直すと狭い課題は動いた

- 内容：次操作を学習。長すぎて読めない教材を退け、完全な履歴と正解を対応づけ直した。
- 結果：v36全42例6→30だが2操作0/10→0/10。v38の正しい症状情報を渡す条件3/30→30/30、固定症状モデル条件1/30→28/30。2操作は両条件0/10→10/10、必要書き込み15/15保持。
- 条件・限界：少数の合成定型例。30/30は症状情報が正しい条件。通常の症状モデルを含めると28/30。v36とは別試験。

### E32 自然な依頼への移行で崩れた

- 内容：依頼と症状を分ける、言い換え対応、残った依頼だけを渡す。
- 結果：v39全120例86→59、必要書き込み45/45→25/45。v41未知関数の実行全体18/56・2操作0/16。v42旧入力4/16に対し学習後0/16。
- 条件・限界：v38とは別の広い試験。履歴を消す診断15/16は、履歴が必要な実運用で採用できる方式ではない。

### E34 読むだけか、次に記録するか

- 内容：読み取り後の次操作を学習し、第二確認役追加とも比較。
- 結果：対24例の正解1→21。全48例25→34。必要継続1/24→24/24だが読み取りだけの終了24/24→21/24。追加確認役は別8例4→1。
- 条件・限界：全体と部分の試験を混同しない。新しい16例の対正解は0/8→2/8にとどまった。

### E35 情報を保つ圧縮形式

- 内容：元定義を復元できる短い入力を用意して学習比較。
- 結果：265入力中512以内が242→265。だが16例の学習前は旧6・短縮0・説明型0、学習後は旧8・短縮2・説明型1。
- 条件・限界：入力が収まる検査とモデルの意味判断は別。

### E36 入力段階を合わせる・結果を残す

- 内容：旧方式反復を対照に3案を比較。
- 結果：固定16例の全条件：初期6、反復対照9、段階対応10、段階対応＋結果保持8。旧56例は初期32、対照37、段階対応36。
- 条件・限界：条件間で呼ぶ/止めるの提示数も異なり、形式変更だけの効果とは断定できない。

### E37 ToolACE・Nemotron追加と旧例保持を分離

- 内容：旧例対照、英語公開例、韓国語公開例、更新幅と旧例保持を検査。
- 結果：v54固定16例：初期10、対照12、英語12、韓国語11。必要継続4/8、5/8、4/8、4/8。v57学習用38判断は前14、旧反復13、混合26、新例だけ30。一方、既存16会話の全手順は10、13、9、8。
- 条件・限界：学習用38判断への適合と、既存会話の実行成績は別。v57新例だけは旧肌360判断が360→358。混合は360を維持しても全手順が悪化。

### E38 実ファイルを使う別の仕事で比較

- 内容：モデル選択からローカルファイル操作と停止まで実行。
- 結果：操作＋保存ファイル20/27→18/27。モデルの終了も含めると11/27→16/27。2操作の操作成功2/6→1/6。不要書き込み0、呼ばない9/9維持。
- 条件・限界：終了の改善と正しい仕事の改善は逆向きだった。
