# Skin Chat：ローカルの小さな試作

2026-11-08更新：現在の構成と未達の部分は [使い方と現在の到達点.txt](使い方と現在の到達点.txt) を参照。標準は症状用モデルによる一発話一操作。汎用の自動連続呼出版は接続確認に失敗したため、標準では無効。

## 起動

Windowsで `demo/start_cosmetics_chat.cmd` をダブルクリックする。ブラウザが開くので、モデルの準備が終わるまで少し待つ。起動した黒いウィンドウは開いたままにする。閉じるとサーバーも終了する。

またはプロジェクトのルートで以下を実行し、ブラウザで `http://127.0.0.1:18770/` を開く。

```powershell
.\.venv-train\Scripts\python.exe demo\cosmetics_chat_server.py
```

## 試した韓国語

1. `피부가 가려워요.`
2. `볼도 건조해요.`
3. `지금 상태를 알려주세요.`
4. `가려움은 이제 없어요.`

上記では、かゆみを記録し、乾燥を追加し、表示後、かゆみのみを「ない」とすることを確認した。別表現での正しさを保証するテストではない。

## 仕組みと範囲

- 韓国語の選択型モデル（`ko-decision-roberta-large`）に、これまでの症状・ツール選択と、ツールを外した例を含めて追加学習したLoRAを適用。`output/training/cosmetics-chat-v1/results.json` に結果。例は合成で、独立確認された実会話ではない。
- 毎回小さい選択型モデルが「記録する／表示する／確認する／何もしない」を選び、記録なら5症状それぞれの更新を判断する。実行と状態保持はプログラムが行い、ローカルQwen3-4Bには動作結果と状態から返答文を作らせる。Qwenに実行可能なツールは渡さない。
- Qwenのサーバーが未起動なら、既存の `scripts/start_qwen3.ps1` を使いバックグラウンドで起動する。利用できない場合はすでに決まった文章で返す。モデルの起動には時間がかかり、GPUメモリが必要。
- 入力はテキストのみ。表示は単一の会話、入力欄、送信ボタンのみ。音声機能やツールの追加・削除画面はない。
- 各返答の下に、実際の選択・処理・更新内容・返答元を表示する。これはモデル内部の思考過程や判断の理由ではなく、実行記録。`state_update` はPythonのメモリ状態更新、`state_read` は状態の読み取りで、外部サービスや実KBの呼び出しではない。
- 状態は現在のページのセッション中、サーバーのメモリにだけある。ページを再読み込みすると新しい会話になり、以前の状態は引き継がれない。サーバー終了時にも消える。ファイルや外部サービスに保存しない。
- 現在は乾燥・吹き出物・赤み・ひりつき・かゆみだけ。製品名・使用時間の抽出、製品DB、外部KB、検索、商品推薦、医療的な判断は実装していない。
- 韓国語の試作。日本語での正確さは確認していない。モデルは間違えるため、本当の肌記録や医療上の判断には用いない。
- 現在の状態を選択モデルに渡す。返答用のQwenには最近の会話4メッセージも渡すが、選択モデルには会話全文を渡していない。「それ」などが何を指すかを一般的に解決するものではない。
