# 会話から肌の状態を記録する

## 概要

Qwenに状態記録と情報検索を接続。最小3/3ターン、広げた合成会話は4/10。追加学習では会話全体20/59→42/59だが、状態完全一致は71/84→58/84。

## 元の実験記録

### E01 学習前のQwen2.5で状態更新と検索

- 内容：Qwen2.5-3B GGUFに2つのツールを接続。
- 結果：最小例3/3ターン。広げた開発例では4/10会話、6/14ターンが全条件一致。
- 条件・限界：未学習モデル・合成の開発例・模擬検索。独立した最終テストではない。

### E02 Qwen2.5 QLoRA：完了は増えたが状態は悪化

- 内容：120判断を用いて60回更新。固定59会話で前後比較。
- 結果：会話全条件20/59→42/59。ターン全条件39/84→57/84。状態完全一致71/84→58/84。
- 条件・限界：学習はNF4、評価は前後とも同じQ4_K_Mベース。合成の固定評価。出力完了と状態の正しさは別。

### E03 未学習Qwen3への交換

- 内容：Qwen2.5-3BからQwen3-4B-Instruct-2507へ交換。
- 結果：会話全条件20/59→41/59。状態は71/84→56/83。
- 条件・限界：モデルの大きさ・テンプレート・量子化も違う。Qwen3はHTTP500で1ターン未完了のため分母が違う。

### E04 KLUE-WoS：対象課題は改善、肌の課題は悪化

- 内容：Qwen3へ200判断の状態追跡学習。
- 結果：WoS状態完全一致9/60→35/60、項目値F1 0.5993→0.9384。肌の会話41/59→30/59。
- 条件・限界：WoSは正しい直前状態を与える1ターン評価。自由な連続実行ではない。

### E05 AI Hub SNS・肌・混合を各2000判断

- 内容：Qwen3で学習教材を3条件に分けた。
- 結果：会話全条件：学習前41/59、SNS15/59、肌38/59、混合13/59。状態：前56/83、SNS19/83、肌51/84、混合19/84。
- 条件・限界：同じ肌の評価。損失が下がっても、この課題の正解は増えなかった。

### E06 Qwen3の動作判断例を学習

- 内容：動作例200判断、または動作100＋AI Hub100を比較。
- 結果：修正後val20/30→22/30・21/30。失敗に沿った12例7/12→9/12・8/12。
- 条件・限界：後者は既知の失敗を踏まえた合成確認。元ラベルと修正ラベルの得点を混同しない。
