# ツール名だけでなく、引数も正しく作る方向へ

## 概要

名前だけでなく値・停止まで検査。xLAMはある120問で79/120だが禁止書き込み3件。固定kotraj監視240問では呼ぶ判断が改善する一方、呼ばない場面に問題が残った。
