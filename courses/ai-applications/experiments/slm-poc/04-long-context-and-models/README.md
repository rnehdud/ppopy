# 長い文章と、複数モデルの検討

## 概要

入力長1024・2048・4096や履歴短縮、選択役と停止役の分離を比較。長い入力が可能になっても精度改善は保証されず、停止判断が悪化する条件もあった。

## 元の実験記録

### E16 1024・2048・4096の追加学習

- 内容：位置埋め込みを拡張し、長い40＋旧短文20判断で各30回更新。
- 結果：各条件の長文30問：1024は13→14、2048は12→12、4096は2→2。既出短文30問24→24。
- 条件・限界：長さごとに長文の評価内容が違う。13→12→2を同じ文章を長くした推移と読まない。

### E17 同じ判断に文章を足した対で学習

- 内容：追加なし・短文だけ・短文と長文の3条件。
- 結果：短文60問49→51→50。長文60問24→23→29。短文＋長文では長文の呼ぶ15/30→10/30、呼ばない9/30→19/30。
- 条件・限界：人工的な付加文章、合成出典。短文と長文で同じ正解を置いた対。

### E18 KUREで過去の発言を選ぶ

- 内容：全履歴2048と、直近優先・KURE優先の短縮を同じ60問で比較。
- 結果：全履歴8/60。1024では両短縮5/60・39件が上限超過。1500では直近10/60、KURE9/60、両方17件上限超過。
- 条件・限界：上限超過を含む60問。入力できた例だけの正解率にすり替えない。ツール実行なし。

### E21 2段構成の最初の比較

- 内容：選択役と呼ぶ・止める判断を分けた。
- 結果：呼ぶ80例の選択35→47。全体120問29→31、呼ぶ40問17→22。ただし同じ2段方式の停止80問19→9。
- 条件・限界：小さい合成の選択評価。停止能力が下がった分も含めて見る。

### E22 EXAONE-JEVと学習データの偏り修正

- 内容：別の小型確認役を追加し、全て呼ぶ正解だった教材を修正。
- 結果：初期EXAONE確認は別120問24/120。v2の96問では元60/96→偏り修正＋調整72/96。呼ぶ59/60、止める13/36。必要値不足の停止は7/24→1/24へ悪化。
- 条件・限界：v1とv2は別評価。v2は12種・必須文字列2つの合成例。実値生成なし。

### E23 値を読む教材へ段階的に修正

- 内容：項目名だけで正解できる教材をやめ、2項目を交差させて学習。
- 結果：v3は全体72/96に対し学習分離71/96。v4は2項目52/168→82/168。v5は128/216→176/216、呼ぶ48/48維持、止める103/168→140/168。
- 条件・限界：v3・v4・v5の母集団は別。2項目の有無を読む試験で任意の引数値生成ではない。

### E24 限定した項目読解は97%、言い換えは悪化

- 内容：4択化、発言と項目の対応学習、言い換え対追加を比較。
- 結果：v7の未知ツール2項目151/168→163/168（97.0%）。同じ更新回数の反復対照161/168。v8の自然表現48例は33→28、全216例201→194。
- 条件・限界：正しいツールを与えた狭い項目判定。v7の差は同更新数対照比2件。v8は別の言い換え評価。

### E25 文を拾う・使用例・質問言語を変更

- 内容：名前変更、文選択、短い例、韓国語質問、確認モデル交換。
- 結果：v10自然文の状態28/40→23/40、全体31/40→27/40。v12元31/40に対し定義例28/40。v13元JEV状態28/40に対しko-decision英語10/40・韓国語10/40。
- 条件・限界：各変更をそれぞれの固定入力で比較。名前だけ変えた39/40→40/40を自然文の改善と呼ばない。

### E26 発言と値を対応づける

- 内容：教材ラベルを修正し、文を直接選ぶ案とも比較。
- 結果：v14の2項目162/200→171/200、反復対照154/200。呼ぶ43/50→46/50、止める133/150維持。v16の2項目126→139/200だが、呼ばない92/120→89/120。
- 条件・限界：値があるかの判定。v14とv16は別条件。
