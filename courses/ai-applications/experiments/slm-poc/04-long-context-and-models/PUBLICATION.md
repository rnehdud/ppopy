# 公開範囲

このディレクトリには実験の記録、選択した結果ファイル、実験用コードを掲載しています。モデル本体・追加学習済み重み・外部データセット・実行環境は含めていません。結果は保存済み実験の記録であり、この公開先で実モデルの実験を再実行したことを意味しません。

`sources.json` はローカル整理時点の原本とSHA-256の対応です。このうち `kure-multiturn-heldout-v1/results.json` と `kure-multiturn-heldout-v2/results.json` の２ファイルは内容を公開対象として確認できていないため、公開版には含めていません。該当する数値はREADMEの要約を参照してください。
