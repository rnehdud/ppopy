### 실행 조건

- 요청 모델 `jev-latest`, 실제 응답 모델 `jev-1.14.0`.
- 총 29회 API 요청 / 231개 질문 / 7건 누적 처리 9.201초. 개별 1.123~1.848초. 단일 실행 관측값이며 성능 보장치가 아님.
- API/형식 오류 경고는 0건. **의미 오류가 없다는 뜻은 아님.** 금액 비용은 계산하지 않음.

### C1 · 제품별 시간 — 핵심 충족

> 오늘 아침에는 라운드랩 1025 독도 토너를 썼고, 저녁에는 일리윤 세라마이드 아토 집중 크림을 발랐어. 지금 피부가 약간 건조해.

**기대:** 두 제품명 분리, 토너→아침 / 크림→저녁, 건조함→mild.
**실제:** 두 정식 이름 후보가 온전히 추출됨. 각각 `affirmed/self/current`, `usage_time=아침/저녁`. `dryness=affirmed`, `severity=mild`.
**남는 확인:** 두 제품 사용 날짜를 모두 오늘로 연결한 것은 문맥 판정. 아직 제품 식별/버전 확인은 아님.

### C2 · 부정과 계획 — 핵심 충족

> 일리윤 세라마이드 아토 집중 크림은 오늘 안 발랐어. 라운드랩 1025 독도 토너는 내일 아침에 써볼 생각이야.

**기대:** 크림→denied, 토너→planned, 두 제품 모두 실제 사용 후보에서 제외.
**실제:** 기대 상태와 일치. 토너 `usage_date=내일 / usage_time=아침`. 두 제품의 `eligible_for_usage_candidate=false`.
**남는 확인:** 크림의 사용 시간은 `unknown(0.40, uncertain)`. 미언급과 모름을 안정적으로 구분하는지는 추가 검증 필요.

### C3 · 제품명 정정 — 핵심 충족

> 어제 밤에 라운드랩 1025 독도 토너가 아니라 일리윤 세라마이드 아토 집중 크림을 썼어. 제품명을 잘못 말했네.

**기대:** 토너는 취소된 언급, 크림만 실제 사용 후보.
**실제:** 토너 `denied/superseded/eligible=false`, 크림 `affirmed/current/eligible=true`. 크림 시점은 어제·밤.
**주의:** `superseded/current`는 명확한 “A가 아니라 B”를 처리하는 코드 규칙의 결과도 포함. Jev만의 성능으로 계산하면 안 됨.

### C4 · 타인과 본인의 같은 증상 — 미충족

> 친구는 라운드랩 1025 독도 토너를 쓰고 피부가 따갑다고 했어. 나는 일리윤 세라마이드 아토 집중 크림을 어제 저녁에 발랐는데 따갑지는 않았어.

**기대:** 친구→토너·따가움 긍정 / 본인→크림·따가움 부정, 두 경험을 분리.
**실제:** 제품 주체는 토너 `other`, 크림 `self`로 구분됨. 그러나 따가움 결과는 하나뿐이며 `state=denied(0.44, uncertain)`와 `subject=other(0.87)`가 결합됨. 근거는 본인의 “따갑지는 않았어.”
**문제:** 본인의 부정과 친구의 대상을 섞음. 증상을 종류당 하나의 레코드로 만드는 현재 구조의 한계.

### C5 · 강도와 발견 시간 — 부분 충족

> 어제 저녁에 일리윤 세라마이드 아토 집중 크림을 발랐어. 오늘 아침에 일어나니 피부가 조금 건조하고 가려움은 심했어. 정확히 언제부터 그랬는지는 모르겠어.

**기대:** 건조함 mild / 가려움 severe, 발견 아침, 시작은 모름.
**실제:** 제품 어제·저녁, 증상 강도와 발견 아침은 일치. 두 증상 `onset_date=unknown`. `onset_time`은 모두 `not_mentioned`로 반환.
**문제:** “언제부터인지 모름”을 시작 날짜에는 반영했으나 시작 시간에는 미언급으로 처리함. 건조함 근거 선택도 `0.41, uncertain`.

### C6 · 반복 사용과 과거/현재 변화 — 미충족

> 라운드랩 1025 독도 토너를 어제 아침이랑 오늘 저녁에 썼어. 어제는 괜찮았는데 오늘은 바른 뒤 볼이 따가웠어. 지금은 따갑지 않아.

**기대:** 사용 사건 두 개, 과거 따가움 긍정과 현재 부정을 각각 보존.
**실제:** 제품 레코드 하나에 날짜·시간 모두 `conflict`. 따가움은 `state=affirmed(0.82)`인데 근거는 “지금은 따갑지 않아.” 발견 시간은 저녁으로 연결.
**문제:** 서로 다른 사건을 충돌 하나로 압축함. 상태와 근거가 모순되며 사용 시간을 발견 시간으로 연결한 판정도 재검토 필요.

### C7 · 부분 이름·모름·거절 — 미충족

> 어제 일리윤 크림을 발랐는데 정확한 제품명은 모르겠어. 몇 시에 발랐는지도 기억 안 나고, 피부 증상은 말하고 싶지 않아.

**기대:** 불완전한 이름을 보존하고 제품 미확정, 사용 시간 unknown, 증상 정보 declined.
**실제:** 제품명이 “일리윤”만 추출됐고 `eligible_for_usage_candidate=true`. 사용 시간은 `unknown(0.48, uncertain)`. 증상 레코드는 없음. 최초 분류의 `information_refused=0.84`는 저장됐지만 관계 출력에 거절 상태가 나타나지 않음.
**문제:** 브랜드만으로 사용 후보가 만들어지고 원문의 “크림”이 누락됨. 어휘 기반 증상 탐지에 걸리지 않는 일반적 거절을 구조화하지 못함.
**주의:** `eligible`은 이름/사용 상태의 실험용 후보 플래그이지 DB 일치·사용자 승인·저장 가능 표시가 아님. 실제 DB 작업은 실행하지 않았음.
