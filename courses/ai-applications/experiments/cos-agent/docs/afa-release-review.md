# AFA PPO 적용 검토와 독립 평가 준비

**B-C02 기본 정책은 도구 우선 규칙으로 유지한다.** 고정 내부 시험에서 3개 PPO seed가 모두 같은 종료 품질을 보였으며, 시작 정보가 없는 16상황과 있는 112조건에서 각각 질문이 한 번씩 더 많았다. 112조건은 동일한 16상황의 시작 정보 변형이다. AFA는 질문을 선택하고 확보한 정보를 반환한다. Python 런타임이 사용자의 답변을 기다렸다가 재개하고, 최종 권고·보류와 도구 실행을 담당한다.

## 실험 범위와 판정 기준

| 항목 | 기준 |
| --- | --- |
| 질문 선택 | 양쪽 정책에 같은 공개 관찰, 허용 질문, 종료 조건을 적용한다. |
| 올바른 종료 | 모든 답을 공개한 기준 결과와 비교한다. B-C02의 두 생활습관 안내 태그는 최종 문구·근거·후속 효과가 모두 같을 때만 같은 결과로 센다. KB 상세 태그 비교는 따로 남긴다. |
| 적용 기준 | 시험을 열기 전에 체크포인트와 코드를 동결한다. 기존 방식이 맞혔던 조건에서 새 오류가 생기지 않고, 모든 seed에서 시작 정보 유무 양쪽 모두 질문이 줄며 이미 알려진 값을 다시 묻지 않아야 한다. |
| 채택 결과 | 내부 시험에서 모든 정책의 종료 품질은 같았다. 채택 기준의 질문 절감 조건이 충족되지 않아 PPO는 명시적으로 선택하는 개발 실험 옵션으로 둔다. |

실제 오프라인 런타임에서도 검증·시험별 128조건을 다시 실행했다. 각 분할에서 규칙과 seed 0 PPO 모두 전체 답을 준 경우의 결과와 128/128건 일치했다. 질문 합계는 123회와 125회였다. 이 검사는 이미 측정한 합성 사례의 통합 재실행이다. 원본은 `outputs/afa-e33/runtime-replay.json`에 있다.

고정 내부 시험에서는 각 정책이 시작 정보가 없는 16상황에서 10건 안내·6건 보류, 있는 112조건에서 70건 안내·42건 보류였다. 안내 오류는 관측되지 않았다. 시작 정보가 없는 집단에서 가족 단위 재표집으로 계산한 질문 차이의 기술적 95% 구간은 −0.25~+0.50회였다. 가족 네 개에서 관찰한 변동이며 실제 사용자 모집단을 추정하는 구간으로 해석하지 않는다. 상황별·가족별 결과는 `outputs/afa-e33/paired-review.json`과 `family-comparison.csv`에 있다.

## 재현

실험 폴더에서 실행한다. 학습한 체크포인트와 동결 파일이 필요하며 검증 보고서는 새 경로에 쓴다.

```powershell
uv run --locked --group rl-train --group tracking python -m beauty_agent.afa.final_evaluation evaluate --manifest outputs/afa-e33/frozen.json --report outputs/afa-e33/test-replay-new.json
uv run --locked --group rl-train --group tracking pytest -q -o norecursedirs= tests
```

학습 설정을 바꿀 경우 새 평가 데이터와 동결 기록을 준비한다. 현재 체크포인트는 로컬 신뢰 파일로만 사용한다.

## 독립 평가 프로토콜 초안

1. **새 상황을 수집·작성한다.** 질문에 따라 달라지는 응답을 미리 정리한다. 완전한 관찰을 먼저 제공하는 사례와 일부만 제공하는 사례, 질문에 답할 수 없는 사례, 복수 카드·정정·제품 근거 경계를 포함한다. 기존 B-C01/B-C02 학습·검증·시험과 v67 파생 자료의 원형을 계보에 명시하고 같은 가족이 두 평가 집합에 걸치지 않도록 검사한다.
2. **사람 검토를 기록한다.** 각 상황의 기대 권고 또는 보류와 근거 출처를 먼저 기록한다. 질문·조회·종료는 허용, 금지, 판단 불가로 표시한다. 적용 범위, 답변이 없는 경우, 상충하는 리뷰를 별도 표시한다. 미검토 결과는 개발용이며 검토자 합의를 주장할 수 없다.
3. **시험을 동결한다.** 케이스·가족·모델·KB·마스크·기준선의 해시와 질문 예산을 기록한다. 개인 민감 정보 없이 합성 입력에서 시작한다. 검토된 평가를 사용하기 전에는 모델·질문 순서 선택과 분리한다.
4. **질문 수와 판단 결과를 함께 보고한다.** 정책별 종료 품질, 질문과 재질문 수, 조기 보류, 금지 행동, 규칙 복구와 최종 권고 근거를 공개한다. 분모는 고유 상황과 가족, 변형 조건 수를 따로 적는다. 재학습에 쓴 사례는 새 시험을 마련한 뒤 비교한다.

이 프로토콜은 독립 자료 수집과 평가를 준비한다. 독립 평가셋, 전문가 합의, 실제 사용자 효과는 현재 검증 전이다. [AFA 누적 기록](afa-policy-progress.md)

## E35–E37 복합 세안 적용 검토

답 없이 재호출하거나 직전 요청과 같은 내용을 다시 보내면, 진행 중인 질문을 반환한다. 새 관찰은 런타임에서 먼저 평가하며, 필수 보류는 진행 중인 질문에도 우선한다.

B-C05와 지원되는 세안 카드가 함께 열리면, 각 질문에 가능한 KB 분기 값을 가정한다. 답에 따라 권고나 보류가 달라지고 더 많은 질문이 불필요해지는 순서를 먼저 고른다. 가능한 값을 동일 가중치로 평가하는 규칙이다. 기존 B-C02 단독 질문 순서와 지원 범위 밖 카드는 기존 규칙을 사용한다.

새 합성 12상황에서 두 순서가 같은 권고 또는 보류를 반환했다. 질문은 55회에서 41회로 14회 줄었다. 현재 기본값은 지원 복합 세안의 결과 우선 순위다. 외부·사람 검토를 거친 결과를 주장하려면 앞의 독립 평가 프로토콜이 필요하다. [복합 세안 평가 자료](../data/afa/compound-v1/README.md)
