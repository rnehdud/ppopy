# B-C02 PPO 학습 전 검증

현재 B-C02 PPO 준비 기록이다. 제품 에이전트의 전체 흐름은 [목표 구조](../../../docs/agent-runtime-target.md)를 참고한다.

첫 PPO 비교용 환경은 세안 도구·마찰·건조를 다루는 B-C02에 한정한다. 도구 응답 4종 × 마찰 응답 4종 × 건조 응답 4종의 가상 상황 64개를 코드에서 재현한다. 도구·마찰 응답이 같은 상황을 한 가족으로 묶고, 같은 가족의 건조 응답 변형 4개를 한 분할에 배치한다. 학습·검증·시험은 각각 8·4·4가족이다. 이전 4개 개발 상황과 E24 우선순위 반례에 해당하는 5가족은 학습에 배치한다.

가상 응답은 명시적인 실험 조건이다. 이 분할은 구조로 나눈 내부 시험이며 외부 사용자 평가나 새 전문가 데이터로 해석할 수 없다. 이미 분석한 v67·기존 합성 자료와 일부 응답 조합이 같을 수 있다. 최초 피부 부위는 얼굴로 고정한다. 제품·프로필도 기존 Stage 0 합성 설정을 사용한다.

| 항목 | 고정값 |
| --- | --- |
| 학습·검증·시험 상황 수 | 32 / 16 / 16 |
| 관찰 | 공개된 도구·마찰·건조의 상태 또는 값, 총 15차원 |
| 행동 | E23의 고정 6종 인덱스와 런타임 마스크 |
| 보상 | 질문당 −1, 기준과 맞지 않는 종료에 추가 −4 |
| 초기 학습안 | MaskablePPO, CPU, seed 0, 4,096스텝 |
| 학습 설정 | rollout 64, 배치 32, n_epochs 4, 학습률 0.0003, gamma 1.0, 보너스 0 |
| 비교 기준 | 도구 우선의 올바른 종료율과 평균 질문 수를 함께 비교 |

실험 폴더에서 **학습 없이 재검증**한다.

```powershell
uv run --locked --group rl-train python -m beauty_agent.afa.ppo_preflight --report outputs/afa-c02-preflight-new.json
```

이 명령은 모든 고정 기준선과 종료 경로를 점검하고 모델 초기화와 마스크를 확인한다. 결과의 `ppo_num_timesteps`는 0이다.

첫 학습을 별도로 시작할 때 아래 명령을 사용한다. 비교 보고서는 고정 기준선 3종과 학습 모델의 학습·검증 결과를 담는다. 최종 시험 배치는 모델과 설정을 확정한 뒤 평가하는 데 사용한다.

```powershell
uv run --locked --group rl-train python -m beauty_agent.afa.ppo_preflight --train-steps 4096 --seed 0 --model outputs/afa-c02-trial-s0.zip --report outputs/afa-c02-trial-s0.json
```

검증·시험에서 도구 우선은 각각 올바른 종료 16/16과 평균 질문 2.25회였다. 첫 PPO 실행은 연결과 개발 성능을 보는 용도다. 같은 품질에서 질문 비용이 줄었는지 확인할 때는 검증 결과로 비교하고, 시험을 확인하기 전에 비교 설정을 확정한다.
