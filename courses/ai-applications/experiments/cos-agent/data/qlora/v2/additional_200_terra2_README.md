# 재발 방지 절차를 적용한 신규 200행 — 개발 후보

사용자 요청에 따라 기존 648행을 보존하고 합성 후보 200행을 추가해요.
안내 154행·보류 46행이며 합계는 848행이에요. 실제 생성·검수 결과와 해시는
아래 실행 기록 절에서 확인해요. 절차 설명만으로 검수 완료를 뜻하지 않아요.

## 작성 전

- 기준은 기존 `qlora-synthetic-dataset-guide.md`, KB v0.6.1과 고정 검증기예요.
- `decision_context`는 `new_product_selection` 또는 `current_routine_review`만
  사용하고 판단 목적이 미상이면 null·unknown으로 남겨요.
- 시나리오 raw를 먼저 설계하고 사용 목적·실제 사용·부위·증상·주체·시간을
  구분해요. 모든 관찰은 `atom_evidence`에 원문 발췌와 슬롯 연결 이유를 남겨요.
- unknown·declined는 ‘없음’으로 바꾸지 않아요. 제품 이름이나 용도로 실제
  사용을 추정하지 않아요. 증상 위치를 제품 접촉 위치로 옮기지 않아요.
- 가까운 기존 사례 ID와 실질적인 조건 차이를 기록해요. 이름·날짜·문장만
  바꾼 변형으로 수량을 채우지 않아요. 유사한 가족은 분할을 같이 유지해요.
- 입력과 판단 근거를 `_inputs.json`에 먼저 동결하고 이후 답변을 작성해요.

## 생성 중

- 한국어로 확인된 사실→구체 안내→근거와 이유→미상·한계를 설명해요.
  고정 헤딩은 solution 3절, hold 2절 그대로 유지해요.
- `guidance`를 그대로 복사하지 않아요. 최소 글자 수를 맞추는 패딩도 하지 않아요.
- 입력의 관찰·허용 근거가 실제로 뒷받침하는 내용만 써요. 일반 문헌의 제한된
  설명을 모든 제품에 확대하거나 특정 개인의 성능·효과로 바꾸지 않아요.
- HOLD에는 개별 루틴·대체 제품을 넣지 않아요. 고정 가이드가 허용하는 연결
  불편 제품의 일시 중단 등 안전 안내와 필요한 확인은 구분해요.
- 한국어 청크는 2~4문장 설명체예요. 영어 청크는 고정 영어 근거 비율을 위한
  등록 출처 요약이며 외부 원전의 직접 인용으로 부르지 않아요.
- 출처 메타데이터는 원본 그대로 복사해요. 합성 방어 청크의 분류는 별도
  메타데이터에 남기고 본문에 ‘방해/오답/시험’ 정답 힌트를 넣지 않아요.

## 독립 검수와 수정

- 작성 담당과 다른 Terra 담당이 입력·답변·실제 KB 카드 전체·저장된 청크를
  읽고 R1–R6 판단과 raw·주장 연결을 행별 기록해요. 자동 검사는 보조예요.
- R1 인용, R2 임상 절제, R3 미상·버전, R4 HOLD 경계,
  R5 관찰·판정·HN·의미 중복, R6 형식·어조를 각각 확인해요.
- 실패한 내용·FAIL 판정·수정 이유를 보존해요. 수정 입력은 답변 전에 다시
  동결하고 독립 재검수해요. 변경된 내용에 과거 PASS를 재사용하지 않아요.
- 감사 기록의 `content_sha256`를 현재 내용과 대조해요. 이 해시 검사는 실제
  의미 검수를 대체하거나 PASS를 자동 생성하지 않아요.
- 같은 GPT 계열 내부 감사는 외부 교차계열 Critic이나 사람 승인으로 세지 않아요.

## 경계와 재현

`development_preview`, `production_enabled=false`를 유지해요. 실제 사용자 수집,
임상 결과·엔진 실행·학습·배포·사람 승인·공식 900행 완료를 주장하지 않아요.
파일럿 사람 승인과 팀 확인은 계속 필요해요. 이번 200행은 신규 합성이므로
기존 v67 재가공 3행이 약 300행 목표를 충족하게 되는 것도 아니에요.

`build_additional_200_terra2.py`는 동결 입력과 작성 답변을 대조해 데이터를 조립해요.
기존 파일 해시를 검사하고 사람의 검수표 기록이 있으면 덮어쓰지 않아요.
고정 검증기·KB·기존 648행은 수정하지 않아요. 원본 실행 보고서는
`outputs/additional_200_terra2/`에 보관해요.

청크를 대조했어요. 실패 내용을 수정하고 현재 해시로 다시 감사한 **200행이 내부 PASS**예요.

불완전하다고 표시하고, A 전체 67행을 한국어 사례별 근거로 다시 검수했어요.

출처 매니페스트 27/27 일치, 전체 보조 안내 검사 오류 0이에요. 기존 0034의 정상

한국어 안내·현재 검수 설명을 작성했고, 고정 비율의 영어 출처 요약은 유지했어요.
과거 원본 감사·수정 증거 안의 영어 raw는 현재 한국어 검수 설명과 구별해요.
의미 중복은 카드·관찰 및 가까운 기존/신규 사례를 실제로 대조했어요. 전체 848행의
모든 쌍에 대해 의미 중복이 전혀 없음을 증명했다고 주장하지 않아요.

### 실패 기록과 재발 방지

초기 형식 검사에는 A 52행의 헤딩 불일치 104개, B의 배열형 불일치 8개와
HOLD 정규식 탐지 1개가 있었어요. 해당 정규식은 과거 사용 시점을 언급한 문장을
권고처럼 탐지했으므로 실제 루틴 누출과 구분하고 의미를 유지해 표현을 수정했어요.
독립 검수에서는 시간 관계·주체·OR 정보 손실·인용 범위·중복·가족 분리 문제를
발견했어요. 고정 기준은 바꾸지 않고 입력/응답을 수정하거나 새 합성 대체로
명시했어요. 확인된 중간 통증의 보류 조건과 관련 제품 일시 중단을 잘못 해석한 감사 지적은 별도
원문 근거와 함께 철회했고 원래 FAIL도 남겼어요.

새 지원 코드에는 입력 동결 시 기존 KB 값 타입 확인, 답변 저장 시 고정 헤딩과
guidance 복사 방지 확인을 추가했어요. 이런 검사는 의미 감사 PASS를 만들지 않아요.
모든 슬롯별 원문 연결과 별도 담당의 실제 내용 검수는 계속 필요해요.

### 재현과 남은 게이트

저장소 루트에서 다음 명령으로 저장된 동결 입력·답변으로부터 신규 데이터를 조립해요.
사람의 검수 기록이 있거나 기존 파일 보호 해시가 다르면 중단해요.

```powershell
python courses/ai-applications/experiments/cos-agent/data/qlora/v2/build_additional_200_terra2.py
python courses/ai-applications/experiments/cos-agent/scripts/validate_qlora_dataset.py --input courses/ai-applications/experiments/cos-agent/data/qlora/v2/additional_200_terra2.jsonl --enforce-ratios --report courses/ai-applications/experiments/cos-agent/outputs/additional_200_terra2/reproduced_200_structure.json
```

원본 실행 보고서와 동결·중간 판본은 로컬 `outputs/additional_200_terra2/`에 있어요.
`outputs/`는 Git에서 제외돼요. 현재 raw·감사·변경 이력은 위의 공유 파일에도 보존했어요.
집계 스크립트는 원본 감사 패킷과 라운드 파일이 있는 작업 환경에서 사용해요.
모델 감사를 자동으로 재실행하거나 새 PASS를 생성하는 명령이 아니에요.

외부 교차계열 Critic, 사람 검수와 팀 승인은 미완료예요. 공식 provenance는
`unreviewed`예요. 기존 Gemini 검수는 바꾸지 않은 파일럿 24행에만 유효해요.
공식 파일럿 사람 승인 0/24, v67 재가공 3행이라는 기존 한계를 유지해요.
848행은 공식 900행 완료가 아니며 학습·임상 정확도·실제 서비스 효과를 뜻하지 않아요.
데이터 생성·검수와 commit·push는 별도 단계예요. 저장소 반영은 사용자의 별도
요청에 따라 진행하며, Linear는 갱신하지 않았어요.
