# 모델별 약점과 변화 추이 — raw 근거 중심

## 결론

900건 E2는 구체적인 답변이 많지만 관찰·표시·효과를 잘못 연결하는 단정이 있습니다. 1,800건 모델은 일부 단정 오류를 줄였으나 이미 확인된 용도까지 미상으로 돌리거나 확인만 요구해 안내가 약해지는 문제가 두드러집니다. 이는 출력에서 관찰한 경향이지 학습 과정의 내부 원인을 확인한 결과는 아닙니다.

| 모델 | 주요 약점 | 해석 |
|---|---|---|
| 900건 E2 | 관찰 대상·실제 행동·제품 표시 혼동, 표시만으로 성능 단정 | PASS 29건으로 가장 많지만 FAIL 17건도 교정 필요 |
| 1,800건 E1 | 안내 부족, 일부 관찰 왜곡·확인된 사실 부정 | FAIL 12건으로 최소. 900건보다 WARN은 많음 |
| 1,800건 E2 | 불필요한 행동 추가, 관찰 부위 변경, 표시 부정 | E1에서 맞았던 일부 답변이 새롭게 틀림 |
| 1,800건 E3 | 과도한 미상 처리, 재확인 반복, 구체 안내 약화 | 일부 오류 회복은 있지만 WARN 29건으로 최대 |

## 분야별 분포

각 칸은 **PASS / WARN / FAIL**, 각 분야 10개입니다. 자동 분류 점수가 아니라 기존 직접 검수 판정의 분야별 집계입니다.

| 사례 유형 | 900건 E2 | 1,800건 E1 | E2 | E3 |
|---|---:|---:|---:|---:|
| 증상 HOLD: hold-0061~0070 | 8 / 0 / 2 | 8 / 0 / 2 | 5 / 1 / 4 | 6 / 1 / 3 |
| 포장 HOLD: hold-0131~0140 | 3 / 3 / 4 | 4 / 4 / 2 | 3 / 4 / 3 | 5 / 2 / 3 |
| 손 세정 순서: sol-0211~0220 | 4 / 2 / 4 | 2 / 5 / 3 | 4 / 4 / 2 | 2 / 6 / 2 |
| 젤 용도·행동: sol-0221~0230 | 3 / 4 / 3 | 4 / 4 / 2 | 3 / 4 / 3 | 1 / 7 / 2 |
| 로션·화장수: sol-0441~0450 | 6 / 3 / 1 | 3 / 7 / 0 | 3 / 5 / 2 | 2 / 5 / 3 |
| 눈가 표시·기록: sol-0451~0460 | 5 / 2 / 3 | 3 / 4 / 3 | 1 / 6 / 3 | 2 / 8 / 0 |

- 포장 HOLD는 900건보다 1,800건 E3에서 PASS가 증가한 부분입니다. 모든 분야가 나빠진 것은 아닙니다.
- 로션·화장수는 1,800건 E1→E3에서 FAIL 0→2→3으로 늘었습니다. 용도 분류와 표시 해석을 집중 점검할 필요가 있습니다.
- 눈가 표시는 E3의 FAIL이 0이지만 WARN 8입니다. 명확한 역행 지시 감소와 충분한 행동 안내 확보는 별개입니다.
- 손 세정·젤에서는 명확한 오류가 줄어도 WARN이 남아 구체 안내의 약점이 해소되지 않았습니다.

## raw와 판정의 연결

아래 인용은 `common_90_raw_pairs.json`의 실제 입력/출력 또는 그 안에 원형으로 저장된 user JSON 값입니다. 전체 문맥은 두 HTML 보고서에서 확인할 수 있습니다.

### 1. 처음부터 지속: 외관 변화의 시점을 통증에 붙임

ID: `syn-hold-0062`

입력 raw:

> 어젯밤부터 보인 변화, 오늘도 그대로
>
> 같은 곳 현재 욱신거림

900건 E2 raw:

> 어젯밤부터 보인 불룩함과 오늘 욱신거림을 함께 설명해 주세요.

1,800건 E3 raw:

> 어젯밤부터 오늘도 욱신거리는 통증이 이어져요.

연결: 어젯밤부터인 것은 외관 변화입니다. 현재 통증의 최초 시작 시점은 없습니다. 900건은 두 시점을 분리하지만 1,800건은 합칩니다. 판정은 900건 PASS, 1,800건 **FAIL→FAIL→FAIL**입니다. 같은 유형의 `syn-hold-0070`도 E1부터 지속돼, 모든 오류를 E2 이후 과적합으로 설명할 수 없습니다.

### 2. 학습 진행 후 추가 행동 발명

ID: `syn-sol-0212`

900건 E2 raw:

> 손가락에 묻은 가루를 얼굴에서 비비기 전에 손을 먼저 씻어 보세요.

1,800건 E1 raw:

> 가루가 묻은 손을 얼굴에서 비비기 전에 손을 먼저 씻어요.

1,800건 E3 raw:

> 손을 먼저 씻고, 그 손으로 얼굴을 비비기 전에 손을 다시 씻는 순서

연결: 손 세정을 얼굴 접촉보다 먼저 하라는 근거를 두 번 세정하라는 행동으로 늘렸습니다. 중간 재오염이나 반복 세정 필요성은 제공되지 않았습니다. 판정은 900건 PASS, 1,800건 **PASS→FAIL→FAIL**입니다.

### 3. 미검증 성능 단정이 사라져도 다른 오류가 생김

ID: `syn-sol-0224`

900건 E2 raw:

> 두 젤을 겹쳐 쓰지 않아도 얼굴에 남은 색조를 제거할 수 있어요.

1,800건 E1 raw:

> 사용 뒤 물로 헹군 뒤에 보습을 해요.

1,800건 E3 raw:

> 얼굴에 어떤 젤을 쓰는지와 얼마나 남는지는 아직 미상이에요.

연결: 900건은 제거용 표시로 실제 제거 성능까지 단정합니다. E1은 단계 분리와 성능 미확인을 보존합니다. E3는 앞의 성능 단정은 없애지만 입력에 제공된 젤의 역할까지 넓게 미상 처리합니다. 판정은 900건 FAIL, 1,800건 **PASS→FAIL→FAIL**입니다. FAIL 수가 같아도 오류 내용은 같지 않습니다.

### 4. 신중한 표현이 확인된 용도의 삭제로 변함

ID: `syn-sol-0443`

입력 raw:

> 유연화장수, 세안 후 얼굴 피부에 사용. 메이크업 제거 표시 없음.

1,800건 E3 raw:

> 현재 제품의 용도와 제거 대상이 확인되지 않았어요.

연결: 색조 제거 성능은 미확인일 수 있지만 유연화장수 용도 자체는 제공됐습니다. 성능 미상과 표시 확인을 분리하지 못했습니다. 판정은 900건 WARN, 1,800건 **WARN→WARN→FAIL**입니다.

### 5. 사용 계획이 제품 표시를 덮어씀

ID: `syn-sol-0449`

입력에는 다리 사용 계획과 얼굴용 메이크업 제거·헹굼 표시가 별도로 제공됩니다.

900건 E2 raw:

> 다리에 쓰려는 로션은 얼굴용 메이크업 제거, 헹굼 표시예요.

1,800건 E2 raw:

> 얼굴용 메이크업 제거용으로 표시돼요. 부위를 바꾸면 보습용이 되는 건 아니에요.

1,800건 E3 raw:

> 다리를 쓰려는 로션은 얼굴용으로 분류하지 않아요.

연결: 사용 예정 부위가 다리라는 사실은 제품 표시가 얼굴용이라는 사실을 바꾸지 않습니다. 판정은 900건 PASS, 1,800건 **WARN→PASS→FAIL**입니다. 단조로운 개선/악화가 아닙니다.

### 6. Epoch 2 오류가 Epoch 3에서 회복하기도 함

ID: `syn-sol-0454`

입력 raw:

> 바깥쪽 눈 주위 피부에 쓰도록 표시돼 있음

1,800건 E2 raw:

> 바깥쪽 눈 주위 피부까지 쓰도록 해석하지 않아요.

1,800건 E3 raw:

> 눈가용이라는 표시를 바깥쪽 눈 주위 피부에도 적용해요.

연결: E2는 명시된 사용 범위를 부정하지만 E3는 복원합니다. 판정은 900건 PASS, 1,800건 **PASS→FAIL→PASS**입니다. 모든 사례가 더 오래 학습할수록 계속 나빠졌다는 주장은 성립하지 않습니다.

## 최적 지점과 한계

1,800건 안에서는 E1이 이 표본의 PASS 최대·FAIL 최소 후보입니다. 그러나 전체 비교에서는 900건 E2가 PASS는 더 많고 FAIL도 더 많습니다. 따라서 단일한 우승 모델보다 900건 E2와 1,800건 E1을 후보로 두고 추가 검수하는 것이 타당합니다.

전체 184건 검증 loss는 E1 1.053719, E2 0.989347, E3 0.987752입니다. 최저 loss E3와 이 60건 의미 판정의 우선 후보 E1이 다릅니다. loss 감소가 입력 충실성이나 구체 안내 향상을 보증하지 않습니다. 다만 이 표본만으로 과적합의 원인이나 전체 모델의 의미 품질을 확정할 수 없습니다.

다음 개선의 초점은 (1) 관찰의 대상·시점·부위를 보존하기, (2) 확인된 표시와 미검증 성능을 분리하기, (3) 미확인은 해당 속성에만 한정하기, (4) 근거 안에서 한 번의 구체 행동을 안내하기입니다. 교정용 자료를 만들 때 이번 검증 사례를 학습에 섞으면 같은 60건은 더 이상 미노출 평가로 사용할 수 없습니다.
