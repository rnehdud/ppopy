# 900건 / 1,800건 학습 raw 답변 비교 — 중간 검토

**전체 검토 완료가 아니에요.** 공통 90개 ID를 기계적으로 정렬했으며, 그중 입력까지 동일한 사례 10건의 입력·문헌·두 답변을 직접 읽었어요. 나머지 답변을 자동으로 PASS 처리하지 않았어요.

## 완료 상태

- Kaggle 1,800건 학습 5 epoch 완료, epoch당 raw 184개 × 5 = 920개 저장.
- 검증 loss 최저는 Epoch 3 (0.987752). Epoch 4 1.008651, Epoch 5 1.032166으로 상승. patience=2가 Epoch 5에서 발동해 최대 epoch와 동시에 종료.
- 비교 체크포인트는 기존 900건 Epoch 2와 신규 1,800건 Epoch 3. 이는 각 실행의 검증 loss 기준이며, 답변 의미 품질의 최적점으로 확정한 것은 아님.
- 기존 검증 90건과 신규 검증 184건이 다르므로 1.132167 → 0.987752를 동일 시험 정확도 향상으로 읽으면 안 됨.
- 데이터 수뿐 아니라 초기 LR(1e-4 → 5e-5), 학습 방식(single GPU → 2-GPU DDP), 일부 wire 입력도 달라 데이터 증가만의 효과를 분리한 실험이 아님.

## 입력 비교

- 공통 ID 90개. 문자열까지 동일 60개. transport 필드만 차이 30개. 그 외 입력 차이 0개.
- 교사 답변 문자열 일치 90/90개.
- 아래 직접 검토 10건은 모두 문자열까지 동일한 60건에서 선정. 구조·문자열 일치 검사는 의미 정확도 검사와 별개.

### syn-sol-0218: 기존 핵심 오류 개선

입력 raw:

```text
얼굴을 씻을 때는 먼저 손에 묻은 오염물을 씻고 미지근한 물로 얼굴을 적신다.
```

900건 Epoch 2 실제 답변:

```text
### 핵심 안내
얼굴을 적시기 전에 손을 씻는 순서로 바꾸지는 않아요. 보습 직전에 손을 씻는 것은 그대로 남겨요.

### 근거 및 이유
얼굴을 씻는 방법은 얼굴에 닿는 순서를 다루고, 손을 씻는 것은 손에 닿는 물질을 제거하는 일로 구분해요 [ref:cleansing-011].

### 확인이 필요한 한계
손을 씻는 시점이 얼굴 적시기 전으로 옮겨도 얼굴의 세안 효과가 달라진다는 근거는 없어요.
```

1,800건 Epoch 3 실제 답변:

```text
### 핵심 안내
보습 직전에만 손을 씻는 것과 손을 씻은 뒤 얼굴을 적시는 것은 달라요. 손을 씻은 뒤 얼굴을 적시는 순서를 살펴보세요.

### 근거 및 이유
얼굴을 씻을 때는 먼저 손에 묻은 오염물을 씻고 미지근한 물로 얼굴을 적신 뒤 씻는 방식이 일반 안내예요 [ref:cleansing-011].

### 확인이 필요한 한계
손을 씻는 시점과 얼굴 적시 시점이 별개라는 점을 확인할 수 있지만, 두 과정을 연결해 보습 효과를 비교할 자료는 없어요.
```

**원문과 판단의 연결:** 900 E2는 문헌의 선후 순서를 거부했지만 1800 E3는 손 세정 후 얼굴 적시기를 안내해 해당 모순을 해소했다. 새 답변 마지막의 보습 효과 비교는 질문에 필요한 핵심은 아니다.

## 해석 범위

- 손 씻기 선후 순서·제품 표시 부위 왜곡 등 일부 중요한 오류가 개선된 실제 예가 있음.
- 무관한 브러시 언급, 구체 행동 안내 부족, 이미 확인된 정보의 재확인 요구, 보류 문장의 모호함이 남음.
- 이 10건은 대표 표본이 아닌 기존 오류·경계 사례의 목적 표집. 전체 정확도·개선율을 계산하거나 1,800건 모델이 항상 우수하다고 주장하지 않음.
- 전체 920개 의미 검수는 아직 완료하지 않음. 현재 후보는 loss 기준 Epoch 3이며 실제 sweet spot 확정에는 동일 입력 전수 대조가 필요.
