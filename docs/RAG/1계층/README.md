# 뽀피 1계층 RAG · 팀 공유본

**2026년 11월 24일 정리본.** 뽀피가 사용자에게 화장품을 어떻게 사용·보관할지 설명할 때 근거로 삼을 자료다. 관리권고 35건, 국내 표시조건 33건, 서비스정책 17건을 담았다. 각 수치는 출처의 수가 아니라 적용 조건과 함께 읽는 기록의 수다.

## 팀에서 먼저 볼 파일

| 팀원이 하려는 일 | 파일과 사용 범위 |
|---|---|
| 사용자에게 줄 안내 찾기 | [관리권고 35건](검색자료/관리권고.jsonl). 각 줄의 `claim_ko`를 `applies_when`과 `limits`와 함께 읽는다. 가이드 직접 인용 6건은 출처를 붙여 원문 그대로 사용한다. 제조사의 완제품 보관 안내 1건은 제품 버전까지 맞을 때 사용한다. |
| 한국 제품의 주의표시 해석하기 | [국내표시조건 33건](검색자료/국내표시조건.jsonl). 공통 3건, 유형별 14건, 함유 성분별 15건, 착향제 표시 1건이다. 25건은 조건별 표시 해석, 복잡한 8건은 원문 조회 전용이다. |
| 뽀피가 병용을 피하도록 안내하는 이유 찾기 | [서비스정책 17건](정책/서비스정책.jsonl). 6건은 성분 관리제품 조합이다. 적용 부위·회차와 제외 조건을 함께 읽는다. 제조 역량 선호도 이 파일에 있다. |
| 출처를 재현하거나 개정판 대조하기 | [출처목록](출처/출처목록.json)에 공식 URL, 원문 버전·해시, 이용 조건이 있다. 가이드와 국내 별표 3개는 원본 PDF도 동봉했다. 웹 원문은 공식 링크에서 확인한다. |
| 카드 전체를 써도 되는지 확인하기 | [기존 카드 61개의 판정](검토/카드_61개_판정.jsonl), [교재 관련 39항목 대조](검토/가이드_39개_대조.jsonl), [추가 자료 검토 이유](검토/추가자료_판정.md), [가이드 전체 범위 확인](검토/가이드_전체범위_검토.md). 검색에는 각 카드에 연결한 확정 기록만 넣는다. |
| RAG 입력 파일 정하기 | [검색설정](검색설정.json)의 파일·모드 목록을 따른다. 출처 PDF 전문이나 검토 메모를 한꺼번에 임베딩하면 보류한 진술도 검색될 수 있다. [무결성 확인 결과](검토/검수결과.json) |

## 어떤 질문에 답할 수 있나

- **사용·보관** — 손과 용기 청결, 사용 후 뚜껑 닫기, 씻은 퍼프·아이섀도 팁 건조, 매장 테스터와 일회용 도구, 표시기한과 품질 변화, 맞춤형화장품의 개봉 후 기간을 다룬다. COSRX 미국 설정 영문 공식몰의 비타민 C 23 세럼 20 g처럼 완제품이 특정되면 개봉 후 냉장 조건도 확인할 수 있다.
- **사용자 상황** — 건조한 피부를 위한 세정 후 보습, 세정용 에몰리언트의 헹굼, 눈 화장품의 사용 부위와 위생, 인그로운 헤어 예방 목적의 습식 면도, 자주 손을 씻는 보건의료 종사자의 손 관리, 야외 활동 시 광보호와 SPF·PA의 표시 의미를 다룬다.
- **표시 해석** — 한국 판매용 AHA 제품이라도 INCI명 하나만으로 고농도 상담 문구를 결정할 수 없다. 예컨대 AHA 5%인 얼굴용 잔류 제품은 일부 시험 사용과 광보호 표시가 적용된다. pH를 모르면 고농도 상담 표시만 미확인으로 남긴다. 반면 10%를 초과하면 해당 상담 조건은 pH 없이도 판별할 수 있다. [고시 별표 1, PDF 10쪽](출처/고시_별표1.pdf#page=10)
- **제조사·제품 지침** — 같은 부위에 순수 비타민 C 관리제품과 카퍼펩타이드 또는 AHA·BHA 각질관리 제품을 겹쳐 사용할 때의 분리 원칙을 설명할 수 있다. 제조사의 개별 표시는 그 제품에 한정하고 뽀피의 보수적 권고는 정책으로 표시한다. 제조 역량 선호는 검증된 기술과 해당 제품의 연결이 있을 때 보조적으로 쓴다.

## 어디까지 검증했나

기존 61개 카드를 서로 겹치지 않게 집계하면 **관리권고가 연결된 카드 30개, 국내 표시조건만 연결된 카드 4개, 서비스정책만 연결된 카드 14개, 보류 13개**다. 한 카드에 관리권고가 하나 연결되어도 카드 전체의 임상적 주장이 입증되지는 않는다. 보류한 13개에는 일반 세안법·약산성 제품 선호·제거와 중첩·유통경로·가품 대응 등이 있다. 카드별로 다음에 대조할 조건과 출처를 기록했다.

가이드는 전체 텍스트와 목차를 탐색했으며, 모든 문장을 정독하거나 최신성을 검증한 상태는 아니다. [전체 범위 확인과 남은 검증](검토/가이드_전체범위_검토.md)을 참고한다.

교재 대조 39항목은 사용 방법 7개, 공통 주의 3개, 유형별 14개, 성분별 15개다. 이 가운데 38개는 가이드의 해당 쪽을 확인했고, 벤조페논-3의 현행 주의 항목 1개는 후속 고시에서 보완했다. 사용자가 촬영한 여섯 장은 다른 책의 지면이므로 두 자료의 쪽수를 구별했다. 가이드의 규정 인용은 개정 4판 발행 당시의 판본이다. 라벨 관련 답변은 동봉한 시행규칙·고시 및 해당 부칙을 사용한다.

## 1계층 적합성 검토

2026년 11월 24일 기준으로 사용·보관·표시 해석을 위한 팀 공유 자료로 사용할 수 있다. 외부 관리권고를 연결한 카드는 61개 중 30개다. 일반 세안법과 약산성 클렌저 선호 등 보류 카드 13개는 소비자 권고의 근거에서 제외한다.

| 질문 예시 | 검색 자료로 답할 수 있는 범위 |
|---|---|
| 이 비타민 C 세럼은 냉장해야 하나요? | 제품명·용량·판매지역·버전과 포장 지시가 일치하면 해당 제품 기록을 사용한다. 제품을 특정하지 못하면 보유품 표시를 확인한다. |
| AHA가 들어 있으면 상담 문구가 필요한가요? | 한국 표시 기준으로 함량 0.5% 이하는 해당 조항에서 제외된다. 0.5% 초과 시 세부 문구를 각각 확인한다. 10% 초과 또는 pH 3.5 미만은 상담 표시 조건이다. [별표 1, PDF 10쪽](출처/고시_별표1.pdf#page=10) |
| 사용하고 남은 탈색제도 뚜껑을 닫아 두나요? | 혼합 잔액에는 일반 용기 보관 문구를 적용하지 않는다. 제품 표시와 혼합 잔액 폐기를 다룬 원문을 조회한다. [별표 1](출처/고시_별표1.pdf) |
| 순수 비타민 C 세럼과 각질관리 제품을 다른 회차에 쓰라는 근거는 무엇인가요? | 제조사의 병용 안내는 해당 완제품에 귀속한다. 다른 제품 조합에 대한 회차 분리는 뽀피의 보수적 정책으로 설명한다. [COSRX The Vitamin C 23 FAQ, Q7](https://www.cosrx.com/pages/faq_the-vitamin-c-23) |

관리권고 35건과 국내 표시조건 33건의 출처·적용 상황을 확인하고, 정책 17건 및 기존 카드 연결을 검수했다. 공식 원문 재대조에는 국내 별표의 농도 경계와 혼합 잔액, 가이드 직접 인용 6건, 미국 자외선차단제 표시, 에몰리언트 용법 및 지정 완제품 사례를 포함했다. 실제 사용자 질문에서 검색 순위·필터·출처 표기가 의도대로 작동하는지는 서비스 연결 후 검증할 항목이다.

모든 경로는 이 폴더를 기준으로 한다. UTF-8 JSONL은 한 줄이 한 기록이다. 서비스에서 권고를 표시할 때에는 각 기록의 출처 표기와 이용 조건을 함께 적용한다. 이 공유본의 검수 범위는 자료와 연결 관계까지다.
