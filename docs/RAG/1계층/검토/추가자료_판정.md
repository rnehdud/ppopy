# 추가 자료의 채택 범위와 재검증 조건

2026-11-24 검토. 한국의 일반 성인에게 화장품 사용 행동을 설명할 때 필요한 자료를 검토했다. 법정 표시에는 어린이·두발·속눈썹 등 개별 제품의 조회용 항목도 들어 있다. 현재 자료로 답할 수 있는 범위는 [카드별 판정](카드_61개_판정.jsonl)에서 확인한다.

| 검토한 내용 | 이번 결정 | 범위를 넓히려면 |
|---|---|---|
| 다른 책의 사진 6장과 식약처 가이드 | 사진은 주제 대조에 사용했다. PDF 143~151쪽의 위생·보관·주의사항에 현행 별표를 연결하고, PDF 160~161쪽의 제품 선택·표시 확인은 기존 근거에 연결했다. 302쪽에서 맞춤형화장품 사용기한과 조제관리사의 내용물 설명을 추가했다. | 사진 원문 자체를 인용할 때는 별도 책의 서지·판본과 이용 조건이 필요하다. 가이드 151쪽의 성분별 표에는 이후 추가된 벤조페논-3 항목이 없다. |
| 반제품·원료 보관, 작업장 온도와 제조 위생 | 소비자 루틴에서 제외했다. 사용 후 뚜껑 닫기, 퍼프와 팁 건조, 어린이 접근 및 직사광선 회피는 채택했다. | 특정 제품의 냉장·폐기 기간은 해당 완제품의 지역·버전별 표시를 대조한다. COSRX 영문 공식몰(미국 설정)의 비타민 C 23 세럼 20 g을 제품 지정 예로 채택했다. |
| 염모·탈색·제모·퍼머 등 | 해당 유형을 식별한 뒤 별표 전체와 제품 표시를 조회하도록 했다. 혼합물 밀폐 보관 등에는 일반 보관 원칙과 다른 지시가 있다. | 개인별 처치나 손상 판단은 일상 화장품 안내 범위를 벗어난다. |
| 건조감·보습·세정·손 | 바르고 두는 에몰리언트 사용 시점, 세정용으로 안내된 제품의 헹굼·건조, 잦은 손 씻기가 있는 보건의료 업무의 손 관리를 채택했다. | 보습 안내 원문의 다음 검토 예정일(2026-10-24)이 지났다. 현재 게시 본문을 확인했고 씻은 뒤 보습은 별도 병원 안내와 비교했다. 일반 얼굴의 보습제 용량·고정 횟수, 특정 pH 선호에는 다른 직접 근거가 필요하다. |
| 눈 화장품·면도 | 눈 감염 당시 쓴 눈 화장품의 처리, 눈가 용도 확인을 채택했다. 털이 피부 안으로 자라는 문제를 예방하려는 습식 면도의 준비·방향·무딘 날 관리를 채택했다. | 눈시림만으로 감염을 판단하거나 습식 면도 근거로 전기헤드의 교체 주기를 정할 수 없다. |
| 광보호와 자외선지수 | 야외 지수 3 이상에서 보호 행동, 미국 내수성 표시를 읽는 방법을 추가했다. 중복되는 국제기관 광보호 안내는 새 근거 수에서 제외했다. | 한국 제품의 내수 지속시간, 눈시림 감소, 보습제 중첩 시 실제 SPF는 개별 표시·완제품 시험을 확인한다. |
| 순수 비타민 C·카퍼펩타이드·각질관리, 레티노이드·산 | 별도 완제품, 같은 부위와 회차, 확인된 관리 목적에 한해 서비스의 보수적 병용 원칙으로 채택했다. 각 제품 표시와 의료진의 개별 지시를 우선한다. | 특정 완제품 안내를 모든 비타민 C 유도체·모든 산·단일 복합 제형으로 확대하려면 직접 근거가 필요하다. |
| 제조 역량과 제품 회수 | 확인된 완제품·제품군·사업장의 기술만 선호에 보조 활용하는 정책을 수록했다. 공지 확인은 관리권고에 수록했다. | 회사명만으로 순위를 정할 수 없다. 실제 회수 판정은 관할 공고 원문·정확한 제품·제조번호·현재 상태를 건별로 확인한다. |
| AAD, 임상·학술자료, CIR·SCCS·CosIng·NIFDC | 재사용 조건이 미확인인 권고는 서지·검토 대상으로, 원료 안전성·기능·농도와 연구대상 한정 시험은 2계층 근거로 다룬다. BEE 소아 습진 연구와 RESTORE 성인 하퇴 시험 결과는 일반 성인의 얼굴에 그대로 옮기기 어렵다. | 서비스에서 쓸 수 있는 권리, 연구대상·제형·신체 부위·평가지표와 주장 간 연결을 확인한다. |
| 국내외 제품 신고·향료 표시 | 국내 착향제 25종 목록과 표시 경계값은 법령 근거로 수록했다. EU 목록과 캘리포니아 제품 신고는 각 관할의 참고 자료로 둔다. | 개별 제품의 법적 상태나 사용자 알레르기는 판매 관할·성분·함량·제품 버전·사용자 이력을 각각 확인한다. |
