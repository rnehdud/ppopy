## 신규 내용과 재검증

- **채택 2건** — SPF의 UVB 표시 의미와 PA의 UVA 표시 의미. 160쪽 원문을 바꾸지 않고 출처와 함께 제시한다. 별도 식약처 설명에서도 일치한다. [식약처 안내](https://www.mfds.go.kr/brd/m_100/view.do?seq=33335)
- **중복·제품별 확인** — 다층 화장수와 헹굼이 필요한지 여부는 제품마다 공식 용법을 확인한다. 사용감은 사용자가 보고한 사실로 다루며 제품 효능의 증거로 쓰지 않는다.
- **후속 검증 후보** — 이상사례를 보고할 때 실제 국내 접수처·현행 서식과 최소 필요 항목, 제품별 회수·제조번호 일치, 성분 또는 완제품별 보관 조건은 각각의 최신 공식 원문이나 해당 완제품을 건별 대조한다.
- **이용 조건** — 가이드는 출처 표시와 변경 금지 조건을 확인했다. 직접 인용 기록의 `display_instruction`과 출처 표기를 사용한다.
