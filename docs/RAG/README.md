# 1계층 자료 안내

[1계층 팀 공유본](1계층/README.md)은 2026-11-24에 정리한 현재 자료다. 검색 입력, 출처와 적용 조건, 보류 항목을 이 폴더에서 확인한다.

[자료수집 로드맵](1계층_RAG_자료수집_로드맵.md)과 [1계층 준비 자료](1계층_준비/명세.json)는 자료 수집·대조 과정의 이력이다. 이력의 판정과 수치는 당시 시점의 기록이므로 현행 판단은 팀 공유본에서 확인한다. FDA 원문 HTML 3개를 포함한다. 이력에 적힌 SkinAnalysis의 다른 경로는 원본 프로젝트의 파일을 가리키며 이 PR에 모두 포함된다는 뜻은 아니다.

이 자료는 RAG 검토·구성용이다. 실제 검색 인덱스와 사용자 서비스 연결 및 답변 품질 검증은 별도다. 공유본의 제조 역량 선호는 제안으로 기록되어 있으며, ppopy의 현행 추천 실행 정책은 source-blind다.
